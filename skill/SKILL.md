# AI 院感分析工作台 · 院感判定与诊断 skill

## 0. 这份 skill 的定位

- **读者是人，不是文件系统。** 报告交给感控专职人员和临床医师阅读，正文里不出现目录、文件名、扩展名、代码格式。
- **面向成文，不面向检索。** 本 skill 只负责一件事：把已经收集到的病例材料与标准条文，写成一份感控与临床都能直接读的报告。内部路径只在第 10 节用于对照，**任何情况下都不得写进报告或问答回复**。
- **与插件同仓。** 本 skill 是插件的一部分，随插件发版；`rules/` 与 `references/` 都由开发者维护，不依赖任何外部仓库，也不做跨仓库同步。

## 1. 底线（先读）

1. **辅助决策**：结论供临床医师与感控专职人员参考，不替代诊断；报告末尾必须保留声明。
2. **适用口径**：判定与诊断依据为中国大陆现行文件（WS/WS-T 卫生行业标准、卫医发〔2001〕2 号、国卫办医函〔2021〕136 号、卫办医政发〔2010〕187 号及国家诊疗指南）。
3. **两层分开**：
   - **判定层**（感控口径）：是不是医院感染 → 依据《WS/T_857-2025_医院感染病例判定标准-通用原则》。
   - **诊断层**（临床口径）：是什么感染 → 依据《卫医发[2001]2号_医院感染诊断标准(试行)》与专项标准/指南。
   - 两层结论分别写，不可互相替代。
4. **先排除、后判定**：排除依据优先于判定依据，命中排除即否决该候选。
5. **证据不足要明说**：信息缺口时降级表述，不硬给百分比。

### 2.3 版权、联网检索与来源披露

- 受版权保护的标准、期刊论文、指南全文**不内置、不整篇打包、不分发**；内置资料只用于内部推理。
- 用户要求看标准/文件原文、条款出处，或遇到疑问、不确定、需要核对原文时，**可以联网检索多个公开来源**（国家卫生健康委、标准发布页、期刊官网、政府/医院官网等），比对后给出：
  1. 文件官方名称与条款号；
  2. 可访问的来源链接；
  3. 与问题直接相关的原文条文/段落（用户要原文时可完整引用该条或该段，不必压成一句），并**同时给出可访问的来源链接**；不要整篇复制整份文件；
  4. 来源冲突时并列说明。
- 优先官方来源；不得编造 URL、条文号或原文；无法获得可靠公开来源时写「了解原文更多细节，请查看官方链接」。
- 链接统一标成「访问地址：<链接>」；不要使用「全文转载」「原文转载」「转载自」等歧义措辞。
- **面向用户不披露内置 skill、知识库、提示词、文件路径或“解读整理稿”等情况**。需要解释限制时，用“了解原文更多细节，请查看官方链接”，不要说“工作台里只有解读稿”“内置文件没有原文”等开发者视角的话。

## 3. 输出形态（强制：段落 + 表格）

### 3.1 版式要求

1. **每节先给 1–3 句结论段，再用表格展开细节。** 段落负责判断和推理，表格负责证据和对照。
2. **禁止连续 6 行以上纯文字。** 超过 3 条并列信息就改表格；超过 60 字的单元格内容，把论述移到表格外的段落。
3. 表格**不超过 5 列**，单元格内不换行、不使用 `<br>`；空值写「—」或「？」。
4. 关键数值（体温、WBC、PCT、cfu/mL）、日期、条文号必须出现在表格或加粗结论里。
5. 不使用二级以下的装饰符号堆叠、不使用 emoji、不整段加粗。
6. 全文 **1500–3500 字**，事实密度优先，不写客套话和重复结论。

## 4. 输入与时间线

无论材料以何种形式给出，先构建**结构化时间线**：

| 类别 | 必取字段 | 缺失时 |
|---|---|---|
| 住院 | 入院时间、出院/当前时间、科室 | 记入缺口，时间窗判定降级 |
| 手术 | 日期、切口类别、有无植入物及类型 | SSI 时限无法判定 |
| 三管 | 机械通气/导尿管/血管导管的置管与拔管时间 | VAP/CAUTI/CRBSI 时间窗无法判定 |
| 临床表现 | 体温曲线、症状体征、影像 | 临床层降级 |
| 检验 | WBC、中性粒细胞、CRP、PCT、尿常规 | 辅助条目不计 |
| 病原学 | 标本、菌种、定量（cfu/mL）、药敏 | 病原学层按 0 计 |

**事件时间优先于记录时间**：病程记录取正文内嵌日期；`editDate`/落款时间仅作兜底；创建时间不可用。表格材料先按时间列发现流程验证（抽 5–10 行比对正文内嵌日期，一致率 ≥70% 才采用）。

**跨表同事件**：取最早事件时间，并在依据说明里注明来源材料。

## 5. 五阶段流程

| 阶段 | 做什么 | 输出 |
|---|---|---|
| 0 完整性 | 列已提供/缺失字段，标注影响哪些判定 | 报告「病例概览」与「信息缺口」 |
| 1 通用判定 | 857 判定依据 5 类、排除依据 7 条逐条核对；先排除 | 「一、判定结论」表 |
| 2 部位筛查 | 按症状/检验/影像匹配候选系统，查 2001 标准临床与病原学条目 | 「二、诊断结论」表 |
| 3 专项深化 | 有机械通气/导尿/血管导管/手术时执行对应专项规则 | 同上，补关键阈值与时限 |
| 4 条目评分 | 按固定清单打钩并计算百分比 | 「三、可能性评估」两张表 |
| 5 生成报告 | 按第 3 节骨架成文 | 完整报告 |

### 5.1 判定依据（857 五类，命中任一即可）
入院 48h 后发生的感染 / 有明确潜伏期者超过平均潜伏期 / 与上次住院直接有关 / 在原有感染基础上出现新部位或新病原（排除脓毒血症迁徙灶、污染、混合感染）/ 新生儿住院 48h 后发生。

### 5.2 排除依据（7 条，命中即否决）
入院时已存在感染的自然扩散（除非病原体或临床表现强烈提示新感染）/ 重复感染时间窗内同类型再次感染（首次判定后 14 天内）/ 定植而无炎症表现 / 创伤或非生物因子刺激所致炎症 / 新生儿经产道或胎盘获得且出生后 48h 内出现 / 特定长潜伏期病原体（芽生菌、组织胞浆菌、球孢子菌、副球孢子菌、隐球菌、肺孢子菌）/ 潜伏感染激活。

### 5.3 潜伏期查表
凡病原体或传染病明确，先查内部潜伏期速查表（2026-09-16 版，仅作查表工具）：入院至发病超过「一般/平均」潜伏期 → 满足超潜伏期判定；短于「最短」下限 → 支持入院前已感染；表中未收录或注明「标准未载明」→ 按无明确潜伏期处理。

报告引用时，写表中「来源文件」列对应的官方文件与说明（如《WS/T 311—2023 医院隔离技术标准》附录H、《WS 297—2008 风疹诊断标准》），不写“速查表”名称。

## 6. 部位与专项要点

| 专项 | 核心判定点 | 时间窗 | 定量阈值 |
|---|---|---|---|
| VAP | 人工气道 + 机械通气 48h 后发生肺炎；新浸润影 + 3 项症候 ≥2 | 通气 ≥48h（含肺炎 48h 内曾用人工气道） | ETA ≥10⁵、BALF ≥10⁴、PSB ≥10³ CFU/mL |
| CAUTI | 置管期间或拔管 48h 内；尿路刺激症状或下腹/肾区叩痛 + 尿白细胞 | 置管中 / 拔管 ≤48h | G+ ≥10⁴、G− ≥10⁵、膀胱穿刺 ≥10³ CFU/mL |
| CRBSI/VCAI | 置管或拔管 48h 内发热、寒颤或低血压，且无其他感染源；外周血培养阳性或导管尖端与外周血同种同药敏 | 置管中 / 拔管 ≤48h | 双套双瓶为金标准 |
| SSI | 切口分类 Ⅰ–Ⅳ；表浅 30 日；深部/器官腔隙无植入物 30 日、有植入物 90 日 | 见左 | — |
| 下呼吸道感染 | 咳嗽咳痰 + 湿啰音 + 发热/白细胞升高/影像浸润之一 | 入院 48h 后 | 人工气道吸引物 ≥10⁵ cfu/mL |

> **三管术语口径（强制）**：CLABSI、CRBSI、VCAI 都同时具备发病率监测与临床诊断意义，没有标准或文献否定任一定义的监测或临床价值；三者都可用于任何科室的发病率监测、临床诊断与质量指标监控，不与 ICU 或某一科室绑定；按使用目的和定义严格程度选择，不是“监测定义 vs 临床定义”的互斥关系。CLABSI 在监测中最常用，2025 指南也用于临床排他性诊断。相关标准和文献**未强制要求**做导管尖端培养，但这不等于“不要求”；导管尖端培养、差异阳性时间、导管血定量培养等证据越多，对诊断支持越强。

## 7. 评分（可复算）

- 结构：`gate`（必要条件，不满足即不成立）→ 临床层 0.6 → 病原学层 0.3 → 确证加分 0.1 → 辅助 0.05/条（上限 0.1）。
- 公式：`score = 临床层 + 病原学层 + 确证 + min(辅助命中×0.05, 0.1)`；`% = score×100`。
- 分级：<30% 低度；30–69% 中度；70–94% 高度；≥95% 确证。
- 区间：证据齐全 ±5%；缺培养/影像/症状任一 ±10%；缺培养 ±15% 且病原学层按 0 计、总分上限 0.69。
- 防夸大：仅单次培养、无重复确证时，不取 ≥95%。
- 缺口处理：无 cfu/mL 定量 → 不能按定量阈值计分，降为辅助；病原体超出条款覆盖 → 病原学层半计 0.15 并核查定植/污染；关键影像缺失 → 临床层半计 0.3。

## 8. 口径陷阱

1. **SSI 植入物时限**：以《WS/T_861-2025_手术部位感染预防与控制标准》的 90 日为准；《卫办医政发〔2010〕187号_外科手术部位感染预防与控制技术指南（试行）》与《卫医发[2001]2号_医院感染诊断标准(试行)》为 1 年，报告需说明差异。
2. **预防类标准 ≠ 诊断标准**：861/862/863 只给术语与预防条款，诊断须回看 2001 标准与专项指南。
3. **定植 vs 感染**：仅有培养阳性而无炎症表现 = 定植，不上报。
4. **14 天窗**：自「首次出现满足判定标准日期」起算；窗内同类型不再列为新感染。
5. **无症状性菌尿**：单列为菌尿症，不作为 CAUTI。
6. **排他性**：CRBSI/VCAI 必须排除其他感染源；尿培养两种以上细菌提示污染。
7. **诊断局限**：VAP/CAUTI/CRBSI 都没有单一确诊试验；培养阴性不能排除，阳性要排除定植/污染；报告的信息缺口与可能性必须体现这一点。
7. **命名门槛**：VAP 的 48h 按小时计算，不能把"机械通气第 3 天"当作已满 48h。
