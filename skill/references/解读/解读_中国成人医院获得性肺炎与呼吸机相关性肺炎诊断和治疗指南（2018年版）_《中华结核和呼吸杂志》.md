# 医院获得性肺炎与呼吸机相关性肺炎（HAP/VAP）诊治要点解读

> **文件属性**：解读文件。本文由开发者独立编写，围绕 HAP/VAP 的判定、分层与处置，对公开文献中的事实、阈值与推荐原则进行解读与整理；表述、结构与表格均为自行组织，未复制原文。本文不是原文献，也不替代原文；正式引用、教学与学术使用请以原文为准。
>
> **参考资料**：中华医学会呼吸病学分会感染学组. 中国成人医院获得性肺炎与呼吸机相关性肺炎诊断和治疗指南（2018年版）. 中华结核和呼吸杂志，2018，41（4）.

## 1. 定义与边界

| 类型 | 定义要点 | 易错点 |
|---|---|---|
| HAP | 入院 48 小时后新发生的肺炎，患者未接受有创机械通气，也不处于病原感染潜伏期 | 无创通气患者发生的肺炎仍归入 HAP |
| VAP | 气管插管或气管切开、机械通气满 48 小时后发生的肺炎；撤机或拔管后 48 小时内出现者仍按 VAP 处理 | "机械通气第 3 天"不等于已满 48 小时 |
| 交叉情形 | 因病情加重而插管的 HAP 患者仍诊断 HAP，但治疗按 VAP 思路处理 | 不要把这类患者直接改判为 VAP 以凑时间窗 |

## 2. 临床诊断

影像学出现**新发或进展性浸润影、实变影或磨玻璃影**，同时具备下列三项中的两项及以上：

| 症候 | 阈值 |
|---|---|
| 发热 | 体温 >38℃ |
| 气道分泌物 | 脓性 |
| 白细胞 | 外周血白细胞高于 10×10⁹/L 或低于 4×10⁹/L |

影像学是基础：常规胸片，尽量做胸部 CT；危重或不能搬动者可用床旁肺超声辅助，但超声不能替代影像学。

## 3. 病原学诊断

### 3.1 可接受的标本与结果

| 标本/方法 | 判定要点 |
|---|---|
| 合格下呼吸道分泌物 | 镜检中性粒细胞 >25 个/低倍视野、上皮细胞 <10 个/低倍视野（或比值 >2.5:1），培养出病原菌且与临床相符 |
| PSB / BALF / 肺组织 / 无菌体液 | 培养阳性且与临床表现相符 |
| 肺组织病理、细胞学或直接镜检 | 见到真菌并有组织损害证据 |
| 血清学 | 非典型病原体或病毒 IgM 由阴转阳，或双份 IgG 呈 4 倍及以上变化 |
| 病毒 | 流行期有接触史，且抗原、核酸或培养阳性 |

### 3.2 定量培养阈值

| 标本 | 提示致病菌的阈值 |
|---|---|
| 痰 | ≥10⁷ cfu/mL |
| 气管导管内吸引物（ETA） | ≥10⁵ cfu/mL |
| 支气管肺泡灌洗液（BALF） | ≥10⁴ cfu/mL |
| 防污染毛刷（PSB） | ≥10³ cfu/mL |

低于阈值不等于排除感染，需结合宿主免疫状态、细菌种类、近期抗菌药物暴露与治疗反应综合判断。机械通气患者气道常有不动杆菌、假单胞菌、念珠菌定植，培养阳性必须与临床表现、涂片吞噬现象、菌落计数、治疗反应一起评估。

### 3.3 血培养与其他

- 成人每次 2–3 套，不同穿刺点，每瓶 8–10 mL；寒战或发热初起、抗菌药物使用前采集最佳。
- 血培养阳性不能证明菌来自肺部（肺部来源仅占菌血症的少数），需排除导管、腹腔、尿路等来源。
- 合并胸腔积液时行诊断性胸腔穿刺，送常规、生化、涂片与培养。
- 分子检测（如宏基因组测序）可作为疑难病例的补充，但呼吸道非无菌，结果解释需谨慎。

## 4. 病情严重程度与耐药风险评估

| 评估 | 要点 |
|---|---|
| 危重标准 | 需要气管插管机械通气；或感染性休克经液体复苏后仍需血管活性药物 |
| 评分工具 | SOFA 侧重器官功能；APACHEⅡ >16 分是死亡独立预测因素；非 ICU 可用 qSOFA（意识改变、收缩压 ≤100 mmHg、呼吸 ≥22 次/分，≥2 分警惕危重） |
| 一般 VAP | 多数应视为危重，但长期机械通气患者的反复 VAP 需结合评分个体判断 |

**MDR 菌感染危险因素**

| 证据等级 | 因素 |
|---|---|
| 证据充分 | 发生 HAP/VAP 前 90 天内静脉用过抗菌药物；住院 5 天后发生的 VAP；病情危重或感染性休克；VAP 前有 ARDS；接受持续肾脏替代治疗 |
| 可能相关 | 既往 MDR 菌感染或定植；反复或长期住院；入住 ICU；结构性肺病；重度肺功能减退；糖皮质激素或免疫抑制剂；耐药菌高发病区；气管插管、胃管、深静脉导管等屏障破坏 |

常见耐药菌的特定线索：产 ESBL 肠杆菌（既往 ESBL 感染/定植、90 天内用过三代头孢）、MRSA（呼吸道定植、病区分离率高）、铜绿假单胞菌（屏障破坏、免疫低下、结构性肺病）、鲍曼不动杆菌（严重基础病、定植）、CRE（CRE 定植、90 天内用过碳青霉烯、高龄、危重、外科术后）。

## 5. 经验性抗感染治疗

### 5.1 时机与原则

- 临床诊断成立、留取病原学标本后**尽早**给药；延迟给药与病死率升高相关。
- 选药依据：病情严重程度、本院/本病区病原谱与药敏、患者耐药风险、器官功能、PK/PD、过敏史。
- 有条件的医院应定期发布本院 HAP/VAP 病原谱与药敏，经验方案据此制定。

### 5.2 分层选择

| 人群 | 策略 | 药物举例 |
|---|---|---|
| HAP 非危重、MDR 低风险 | 单药 | 抗铜绿 β-内酰胺酶抑制剂合剂、抗铜绿青霉素类、抗铜绿三/四代头孢、喹诺酮类 |
| HAP 非危重、MDR 高风险 | 单药或联合 | 抗铜绿 β-内酰胺酶抑制剂合剂或碳青霉烯类；必要时联合喹诺酮或氨基糖苷类；有 MRSA 风险加糖肽类 |
| HAP 危重 | 联合 | 上述 β-内酰胺类 + 喹诺酮或氨基糖苷类；有 MRSA 风险加糖肽类；XDR 阴性菌风险加多黏菌素或替加环素 |
| VAP MDR 低风险 | 单药或联合 | 抗铜绿青霉素/头孢/β-内酰胺酶抑制剂合剂/碳青霉烯/喹诺酮/氨基糖苷 |
| VAP MDR 高风险 | 联合 | 抗铜绿 β-内酰胺类 + 喹诺酮或氨基糖苷；按风险加抗 MRSA、抗 XDR 药物 |

注意事项：通常不联合两种 β-内酰胺类；氨基糖苷类只用于联合治疗；呼吸道有 MRSA 定植或病区分离率高时经验性覆盖 MRSA。

## 6. 目标治疗与常见耐药菌

| 病原 | 推荐要点 |
|---|---|
| MRSA | 糖肽类（万古霉素/去甲万古霉素/替考拉宁）或利奈唑胺；万古霉素谷浓度一般 10–15 mg/L，重症可 10–20 mg/L 并给负荷量；替考拉宁需负荷后维持 |
| 产 ESBL 肠杆菌 | 轻中度：头霉素类、氧头孢烯类、β-内酰胺酶抑制剂合剂；中重度：碳青霉烯类，必要时联合喹诺酮或氨基糖苷；避免单用三代头孢 |
| CRE | 多黏菌素、替加环素、头孢他啶/阿维巴坦为主；按 MIC 决定是否联合磷霉素、氨基糖苷或碳青霉烯；碳青霉烯 MIC 很高时避免使用 |
| 铜绿假单胞菌 | 大剂量、延长滴注（如哌拉西林/他唑巴坦 4.5 g q6h、滴注 3 小时）；MDR/XDR 联合用药 |
| 鲍曼不动杆菌 | 舒巴坦制剂（MDR 时舒巴坦可加量至 6–8 g/d）、碳青霉烯、多黏菌素、替加环素、四环素类；XDR/PDR 联合 |
| 嗜麦芽窄食单胞菌 | 磺胺甲噁唑/甲氧苄啶为首选之一，可联合 β-内酰胺酶抑制剂合剂、氟喹诺酮、四环素类；对碳青霉烯类天然耐药 |

## 7. 疗程、评估与降阶梯

| 项目 | 要点 |
|---|---|
| 早期评估 | 经验治疗 48–72 小时评估体温、氧合、分泌物、白细胞、影像与标志物 |
| 疗程 | 一般 7 天或以上；初始治疗恰当、单一病原、无脓肿/坏死性肺炎、免疫正常者 7–8 天；重症、XDR/PDR、肺脓肿、坏死性肺炎、免疫缺陷者延长 |
| 降阶梯 | 获得病原学与药敏后，由联合转单药、广谱转窄谱 |
| 无效时 | 重新评估病原（是否覆盖、是否耐药、是否混合感染）、并发症与其他感染灶；拓宽鉴别诊断 |
| 停药 | 结合临床、影像与 PCT 动态；PCT 下降有助于缩短疗程，但不能替代临床判断 |

## 8. 辅助治疗

- **气道管理**：翻身拍背、体位引流、吸痰、必要时支气管镜；氧疗维持 SaO₂ >90%。
- **循环**：液体复苏，必要时血管活性药物维持平均动脉压 >65 mmHg。
- **血糖**：控制在 ≤10 mmol/L。
- **营养**：尽早肠内营养；7–10 天能量/蛋白不足 60% 目标时补充肠外营养。
- **糖皮质激素**：仅建议用于合并血流动力学不稳定的重症患者。
- **吸入抗菌药物**：仅用于 MDR 革兰阴性杆菌、全身用药肺内浓度不足、病原敏感者；可用阿米卡星、妥布霉素、多黏菌素；疗程 14 天或至脱机。不能替代全身治疗。
- **应激性溃疡预防**：不常规使用抑酸剂；有出血风险时用，注意抑酸可能增加 HAP/VAP 风险。

## 9. 预防（VAP 集束化）

| 措施 | 要点 |
|---|---|
| 体位 | 无禁忌时床头抬高 30°–45° |
| 声门下吸引 | 预计机械通气 >48–72 小时者使用带声门下吸引的气管导管 |
| 气囊压力 | 维持 ≥25 cmH₂O；放气或拔管前清除气囊上分泌物 |
| 口腔护理 | 生理盐水/氯己定/聚维酮碘冲洗或刷洗，每 6–8 小时；0.12% 氯己定 15 mL 每日 2 次可降低 VAP |
| 镇静与脱机 | 避免不必要的深度镇静，每日唤醒并评估自主呼吸试验，尽早拔管 |
| 减少有创通气 | 优先无创通气、经鼻高流量氧疗；严格掌握插管指征 |
| 呼吸机管路 | 冷凝水收集瓶保持最低位并及时清理；不常规频繁更换管路，污染或故障时更换 |
| 肠内营养 | 尽早肠内营养；误吸高风险者可经鼻肠管；不常规监测胃残余量 |
| 其他 | 手卫生、无菌操作、目标性监测、合理使用抗菌药物；不常规用益生菌、不常规用镀银导管、SOD/SDD 需权衡 |

## 10. 判定与评分中的常见误区

1. 把入院 48 小时内发生的肺炎算作 HAP/VAP。
2. VAP 的 48 小时按"天数"而非小时计算，导致命名错误。
3. 培养阳性即诊断，忽略定植、污染与临床表现。
4. 只做痰培养、不做定量或不做血培养，病原学层证据不足。
5. 不排查肺外感染源与易混淆的非感染性疾病（肺栓塞、肺不张、ARDS、肺水肿、肿瘤等）。
6. 经验性治疗起点过晚，或获得药敏后不及时降阶梯。
7. 疗程一律"14 天"，忽略 7–8 天的适用条件。
8. 把吸入抗菌药物当作常规治疗。

## 补充：鉴别、评分、四步流程与剂量

### 补充一：鉴别诊断

| 类别 | 例子 | 鉴别要点 |
|---|---|---|
| 系统性感染累及肺 | 导管相关血流感染、感染性心内膜炎 | 找肺外病灶，血培养 |
| 局灶性感染累及肺 | 膈下脓肿、肝脓肿 | 腹部影像与体征 |
| 非感染性 | 肺栓塞/肺梗死、肺不张、ARDS、肺水肿 | 病史、影像、BNP、超声 |
| 其他 | 肿瘤、支扩、药源性肺病、结缔组织病、神经源性发热 | 基础病与用药史 |

### 补充二：严重程度

- SOFA：呼吸（PaO₂/FiO₂）、凝血（血小板）、肝（胆红素）、心血管（MAP/升压药）、中枢（GCS）、肾（肌酐/尿量）六项；取每日最差值。
- APACHEⅡ >16 分是 VAP 死亡的独立预测因素。
- qSOFA：意识改变、收缩压 ≤100 mmHg、呼吸 ≥22 次/分；≥2 分警惕危重，适用于非 ICU 快速筛查。
- HAP 危重：需要插管机械通气，或感染性休克经液体复苏仍需升压药。
- VAP 一般视为危重；长期有创通气者反复 VAP 需结合评分个体判断。

### 补充三：四步流程

1. 诊断与评估：临床诊断、鉴别、严重程度、MDR 风险。
2. 采样与经验治疗：留取呼吸道/血标本后尽早给药。
3. 48–72 小时再评估：有效则降阶梯；稳定且培养阴性可试停；无改善则查病原、并发症、其他感染灶；培养阴性则拓宽鉴别。
4. 动态监测与疗程：结合临床、影像、PCT 决定停药。

### 补充四：药物剂量速查

| 药物 | 要点 |
|---|---|
| 万古霉素 | 重症负荷 25–30 mg/kg；谷浓度一般 10–15 mg/L，重症 10–20 mg/L |
| 替考拉宁 | 6–12 mg/kg（或 400–800 mg）q12h×3 次负荷，后 400 mg qd |
| 哌拉西林/他唑巴坦 | 可用至 4.5 g q6h，延长滴注 3 小时 |
| 多黏菌素 E（雾化） | 30–60 mg 基质（约 100–200 万 IU），q8–12h，现用现配 |
| 阿米卡星（雾化） | 400 mg bid 或 25 mg/kg qd |
| 妥布霉素（雾化） | 300 mg q12h |

> 剂量为指南推荐范围内的要点，具体给药需按体重、肝肾功能、MIC 与 PK/PD 调整。

### 补充五：特殊人群

- 免疫抑制宿主：病原谱更广，需覆盖真菌、病毒、肺孢子菌等；必要时早期侵入性诊断。
- 老年/误吸风险：注意吞咽评估、床头抬高、口腔护理。
- 术后/长期卧床：注意肺不张、误吸、深静脉血栓等非感染性原因。

### 补充六：采样策略与病原谱

| 人群 | 采样策略 |
|---|---|
| HAP | 先经非侵入性方法留取呼吸道分泌物涂片与半定量培养；经验治疗无效、怀疑特殊病原或常规方法阴性时，再考虑 BALF/PSB 等侵入性采样 |
| VAP | 常规经气管导管吸引分泌物涂片与半定量培养；必要时侵入性采样；每周 2 次气道培养有助于预测病原；定量培养转阴可辅助判断停药 |

常见病原以革兰阴性杆菌为主（鲍曼不动杆菌、肺炎克雷伯菌、铜绿假单胞菌、大肠埃希菌等），革兰阳性球菌中 MRSA 需重点考虑；免疫抑制、长期住院或反复抗菌药物暴露者还应考虑真菌、病毒与少见病原。

### 补充七：诊断局限与争议

- **临床诊断是组合判断**：影像加症候没有特异性，也没有无创金标准；同样的影像可见于肺水肿、肺不张、ARDS、肺栓塞与肿瘤。
- **病原学受多因素影响**：痰/ETA 易被定植菌污染，BALF/PSB 更准确但有创；培养需时间，采样的时机会影响结果；既往抗菌药物会降低培养阳性率。
- **血培养只代表菌血症**：肺部来源占少数，阳性需排除导管、腹腔、尿路等其他来源。
- **分子检测不等于致病**：核酸阳性可能来自定植或污染，需结合临床与定量/涂片。
- **评分不是诊断工具**：SOFA/APACHEⅡ/qSOFA 用于严重程度与预后分层，不能替代病原学与影像判断。

写作提示：把"临床诊断成立"与"病原学证据强度"分开写；证据不足时在信息缺口里说明，不要用确定性措辞。

### 补充八：HAP 预防、免疫抑制与 HCAP/VAT

**HAP 预防（非 VAP 部分）**

| 措施 | 要点 |
|---|---|
| 防误吸 | 床头抬高 30°–45°，合理喂食 |
| 减少定植 | 氯己定口腔护理、氯己定擦浴、SOD；益生菌证据有限，免疫缺陷或菌群移位风险者避免 |
| 治疗基础病 | 营养支持、纠正水电解质/低蛋白/高血糖、心肺治疗与康复、气道廓清；围手术期（胸腹部手术）加强气道湿化与通畅；术后早下床、少用镇静 |
| 患者管理 | 器官移植、粒细胞减少等严重免疫抑制者保护性隔离；MRSA/CRAB/CRPA/CRE 感染或定植者接触隔离 |

**免疫抑制宿主**

- 病原谱更宽：除常见细菌外，还要考虑曲霉、肺孢子菌、隐球菌、接合菌等真菌，巨细胞病毒、呼吸道合胞病毒、单纯疱疹病毒等病毒，以及诺卡菌、军团菌、结核分枝杆菌。
- 诊断：病情允许时尽量做胸部 CT；常规涂片与细菌培养往往不够，应按免疫缺陷类型加做真菌、病毒、结核等检测，必要时侵入性采样。
- 治疗：先评估肺炎严重程度与免疫缺陷程度，避免覆盖不足，也避免“全覆盖”过度治疗；同时重建免疫（升粒细胞、停减免疫抑制药、补充免疫活性物质、控制基础病）。

**HCAP / VAT / 早发迟发**

- **HCAP**：我国不采用这一概念；应重视区域耐药特点，全面评估耐药菌危险因素，不必刻意区分是否属于 HCAP。
- **VAT**：目前无统一诊断标准，是否为独立疾病仍有争议；不建议常规抗感染治疗。但对高度疑似 VAP、病情进行性加重、因条件限制无法取得影像依据的危重患者，可在严密监测下审慎经验性治疗。
- **早发/迟发**：不再以发病时间单独决定经验性用药；按 MDR 危险因素与病情严重程度分层。
