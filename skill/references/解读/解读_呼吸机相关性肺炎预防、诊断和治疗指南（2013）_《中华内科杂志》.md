> **参考资料**：中华医学会重症医学分会. 呼吸机相关性肺炎诊断、预防和治疗指南（2013）. 中华内科杂志，2013，52（6）：524–543. DOI：10.3760/cma.j.issn.0578-1426.2013.06.024

## 1. 定义与分型

| 项目 | 要点 |
|---|---|
| VAP | 气管插管或气管切开的患者，机械通气满 48 小时后发生的肺炎；撤机或拔管后 48 小时内出现者仍属 VAP |
| 早发 VAP | 机械通气 ≤4 天发生，病原体多为对常用抗菌药物敏感者（如 MSSA、肺炎链球菌） |
| 晚发 VAP | 机械通气 ≥5 天发生，耐药菌比例高（铜绿假单胞菌、鲍曼不动杆菌、MRSA 等） |
| 我国常见病原 | 铜绿假单胞菌、鲍曼不动杆菌为主；部分早发 VAP 也可由耐药菌引起 |

## 2. 临床诊断

影像学见新发或进展性浸润影，同时具备下列三项中的两项及以上，可临床考虑 VAP：

| 症候 | 阈值/表现 |
|---|---|
| 体温 | >38℃ 或 <36℃ |
| 白细胞 | 外周血高于 10 或低于 4（×10⁹/L） |
| 气道分泌物 | 气管支气管内出现脓性分泌物 |

同时需排除肺水肿、ARDS、肺结核、肺栓塞等可解释影像与症状的疾病。组织病理是诊断金标准，但临床难以常规获取；临床表现与影像均缺乏特异性，因此不能仅凭单一指标确诊。

## 3. 病原学诊断

### 3.1 标本与方法

| 方法 | 特点 | 阳性阈值 |
|---|---|---|
| 气管导管内吸引（ETA） | 快速、简便、费用低；易被上气道定植菌污染 | ≥10⁵ CFU/mL |
| 经支气管镜防污染毛刷（PSB） | 侵入性，准确性较高 | ≥10³ CFU/mL |
| 支气管肺泡灌洗（BAL） | 侵入性，可同时行细胞学与病原学检查 | ≥10⁴ CFU/mL |

疑诊 VAP 时应在经验性用药前留取标本；有条件的单位应开展定量培养。PSB 与 BAL 的准确性优于 ETA，但操作门槛更高。

### 3.2 涂片与快速判断

- 气道分泌物革兰染色涂片可快速区分革兰阳性菌、革兰阴性菌与真菌。
- 以"≥2% 白细胞内见吞噬微生物"为阳性标准，涂片对早期判断病原类型有参考价值，但阳性预测值有限，不能单独作为用药依据。
- 培养需 48–72 小时，涂片与分子检测可缩短早期决策时间。

### 3.3 血培养与胸腔积液

- 血培养是菌血症诊断的金标准，但对 VAP 的敏感性不高（多不超过 25%）；ICU 患者血培养阳性常来自肺外（导管、尿路等），由肺炎引起的菌血症比例较低。
- 合并胸腔积液或怀疑脓胸时，行诊断性胸腔穿刺，送常规、生化、涂片与培养。

### 3.4 临床肺部感染评分（CPIS）

CPIS 综合体温、白细胞、气道分泌物、氧合指数、影像进展与气道分泌物培养六项，用于量化肺炎可能性与严重程度。简化 CPIS 去除培养项，便于早期评估。其诊断敏感性与特异性中等，更适合动态评估病情与指导疗程，而非单独确诊工具。

### 3.5 生物标志物

- CRP 特异性低，受非感染因素影响。
- PCT 对细菌感染有提示价值，动态变化可用于指导抗菌药物使用与停药；但单独诊断 VAP 的证据不足。
- sTREM-1、G 试验、GM 试验在 VAP 中的应用证据有限，不作为常规诊断依据。

## 4. 治疗

### 4.1 经验性治疗

| 决策点 | 要点 |
|---|---|
| 时机 | 临床诊断 VAP 后 24 小时内启动经验性治疗；延迟给药与病死率升高、住院时间延长相关 |
| 选药依据 | 早发/晚发、本院或本病区病原谱与耐药谱、患者 MDR 高危因素（90 天内用过抗菌药物、免疫抑制、住院 >5 天、耐药高发病区等） |
| 早发、低危 | 不必常规使用广谱药物，按常见敏感病原选择 |
| 晚发、MDR 高危 | 选择能覆盖铜绿假单胞菌、鲍曼不动杆菌、MRSA 等的广谱方案 |
| 单药 vs 联合 | 常规单药；考虑 MDR 革兰阴性杆菌（尤其铜绿假单胞菌、鲍曼不动杆菌）时可联合，以提高初始覆盖合理性 |

### 4.2 目标治疗

获得病原学与药敏后应及时转为目标治疗。常见耐药菌的处理原则：

| 病原 | 原则 |
|---|---|
| 铜绿假单胞菌 | 按药敏选择抗铜绿 β-内酰胺类、碳青霉烯、喹诺酮或氨基糖苷；重症/MDR 可联合；注意足量、延长滴注 |
| 鲍曼不动杆菌 | 尽量依据药敏；MDR/XDR 常需含舒巴坦制剂、碳青霉烯、多黏菌素、替加环素等两类或以上联合 |
| 产 ESBL 肠杆菌 | 避免单用三代头孢；轻中度可选头霉素、氧头孢烯或 β-内酰胺酶抑制剂合剂，重症选碳青霉烯 |
| MRSA | 万古霉素、替考拉宁或利奈唑胺；按 MIC、肺组织穿透与病情选择，注意谷浓度 |

### 4.3 雾化吸入抗菌药物

- 仅作为**辅助**手段，用于全身治疗疗效不佳的 MDR 非发酵菌（铜绿假单胞菌、鲍曼不动杆菌）感染。
- 常用氨基糖苷类（妥布霉素、阿米卡星）或多黏菌素；雾化颗粒以 1–5 μm 为宜。
- 可提高气道局部浓度，但不降低病死率；注意支气管痉挛、气道梗阻等不良反应，不常规用于所有 VAP。

### 4.4 疗程与降阶梯

| 项目 | 要点 |
|---|---|
| 疗程 | 一般 7–10 天；初始治疗恰当、单一病原、无脓肿、免疫正常者可短疗程；治疗无效、MDR、复发高风险或免疫缺陷者延长 |
| 降阶梯 | 经验治疗 48–72 小时后评估，获得药敏后由广谱转窄谱、联合转单药 |
| PCT 指导 | PCT 低水平或较治疗前明显下降时可考虑降阶梯或停药；持续升高提示需调整方案（阈值与判断需结合临床） |
| CPIS 指导 | CPIS 动态变化可辅助评估疗效与停药时机，不能替代临床判断 |

## 5. 预防

| 类别 | 措施 |
|---|---|
| 器械相关 | 气囊压力维持适当（一般 ≥25 cmH₂O）；气囊上分泌物及时清除；声门下分泌物吸引；呼吸机管路冷凝水不倒流、收集瓶保持低位；湿化液使用无菌水并定期更换；不频繁更换管路 |
| 操作相关 | 手卫生、无菌操作；床头抬高 30°–45°；口腔护理；避免不必要的深度镇静；每日评估脱机与拔管；尽早肠内营养；减少误吸 |
| 药物相关 | 不常规使用益生菌预防；SOD/SDD 需权衡耐药风险；应激性溃疡预防应掌握指征，抑酸可能增加肺炎风险；不常规使用镀银导管 |
| 集束化 | 将上述核心措施组合执行并核查依从性，比单一措施更有效 |

## 6. 与 2018 版的主要差异（便于工作台选择引用）

| 主题 | 2013 版 | 2018 版 |
|---|---|---|
| HAP 与 VAP | 以 VAP 为主，HAP 未细分 | 明确区分 HAP 与 VAP，HAP 不包括插管患者 |
| 早发/晚发 | 以 4 天/5 天分界 | 更强调 MDR 危险因素而非单纯时间分界 |
| 疗程 | 7–10 天 | 一般 7 天以上，适宜者 7–8 天 |
| 经验性方案 | 按早发/晚发与 MDR 风险 | 按病情严重程度 + MDR 风险分层，方案更细 |
| 评分 | CPIS | SOFA/APACHEⅡ/qSOFA + 危重标准 |

报告引用时按病例实际采用的版本标注，不要混用两版的时间窗与疗程。

## 7. 判定与评分中的常见误区

1. 把"机械通气第 3 天"当作已满 48 小时。
2. 只凭痰培养阳性诊断 VAP，忽略定植与污染。
3. 不做定量培养，无法按阈值计分。
4. 把血培养阳性直接归因于肺部。
5. 忽略非感染性鉴别（肺水肿、ARDS、肺栓塞、肺不张）。
6. 经验性治疗延迟超过 24 小时。
7. 疗程一律 14 天或过早停药。
8. 把雾化抗菌药物当作常规治疗。

## 8. 与工作台评分条目的对应

| 评分层 | 对应事实 |
|---|---|
| 临床层 | 新浸润影、体温异常、白细胞异常、脓性分泌物 |
| 病原学层 | ETA ≥10⁵、PSB ≥10³、BAL ≥10⁴ CFU/mL；涂片吞噬现象 |
| 确证加分 | 肺组织病理、无菌体液阳性、双份血清抗体变化 |
| 辅助项 | PCT/CRP、CPIS、氧合指数、影像进展 |
| gate/排除 | 48 小时时间窗、非感染性鉴别、定植与污染 |

## 补充：证据等级、CPIS 与治疗细节

### 补充一：证据等级

指南用 1A、1B、1C 等标注推荐；数字表示推荐强度，字母表示证据质量。阅读时先看推荐强度，再看证据质量；低级别推荐不等于可以忽略，但需要结合本地条件。

### 补充二：CPIS 六项

| 项目 | 说明 |
|---|---|
| 体温 | 发热或低体温 |
| 白细胞 | 升高或降低 |
| 气道分泌物 | 量与性质 |
| 氧合指数 | PaO₂/FiO₂ |
| 影像 | 肺部浸润进展 |
| 气道分泌物培养 | 简化版可去除 |

CPIS 诊断敏感性与特异性中等，更适合动态评估严重程度、指导疗程，而不是单独确诊。

### 补充三：治疗细节

| 决策点 | 要点 |
|---|---|
| 时机 | 临床诊断后 24 小时内启动经验性治疗 |
| 单药/联合 | 常规单药；MDR 革兰阴性杆菌风险高时联合，确保初始覆盖 |
| 目标治疗 | 获得药敏后转为窄谱/单药 |
| 雾化抗菌药 | 仅作为 MDR 非发酵菌的辅助，不常规 |
| 疗程 | 一般 7–10 天；治疗反应好、单一病原、无脓肿者可短疗程 |
| 降阶梯 | 48–72 小时评估，广谱转窄谱、联合转单药 |
| PCT 指导 | 低水平或明显下降可考虑降阶梯/停药；持续升高提示调整 |
| 糖皮质激素 | 不常规用于 VAP；合并感染性休克按休克原则处理 |
| 物理治疗 | 促进分泌物清除，但不作为改善预后的独立手段 |

### 补充四：鉴别

肺不张、肺水肿、ARDS、肺栓塞、肺结核、其他肺炎、气道定植；结合影像、病程、病原学与治疗反应判断。

### 补充五：危险因素

| 类别 | 因素 |
|---|---|
| 宿主 | 高龄、慢性肺病、糖尿病、免疫抑制、意识障碍、误吸、营养不良、长期卧床、吸烟 |
| 医疗 | ICU 滞留、机械通气时间、镇静剂、抑酸药、胃管、平卧位、呼吸道侵袭性操作、交叉感染 |

### 补充六：预防措施细节

| 措施 | 2013 版要点 |
|---|---|
| 呼吸回路 | 不常规定期更换，污染或故障时更换 |
| 湿化 | 可用加热湿化器或热湿交换器；热湿交换器每 5–7 天更换，污染或阻力增加时更换 |
| 细菌过滤器 | 不常规使用 |
| 密闭式吸痰 | 除非破损或污染，不每日更换 |
| 声门下吸引 | 建立人工气道者应做声门下分泌物引流 |
| 气囊压力 | 定期监测，保持在 20 cmH₂O 以上；2018/863 提高到 ≥25 cmH₂O，报告按所引版本写 |
| 床头 | 抬高 30°–45° |
| 手卫生 | 加强手卫生可降低 VAP |
| 口腔护理 | 洗必泰口腔护理可降低 VAP |
| 插管路径 | 经鼻插管增加鼻窦炎风险，宜经口 |
| 气管切开 | 早期气管切开不降低 VAP 发病率 |
| 肠内营养 | 尽早肠内营养；高误吸风险可经鼻肠管 |
| 益生菌 | 不常规用于预防 |
| SDD/SOD | 可考虑，但需权衡耐药风险 |
| 应激性溃疡预防 | 掌握指征，抑酸可能增加肺炎风险 |
| 抗菌药物预防 | 不常规雾化或静脉使用抗菌药物预防 VAP |
| 集束化 | 抬高床头、每日唤醒/脱机评估、应激性溃疡预防、深静脉血栓预防等组合执行 |
| VAE | 附录提供呼吸机相关事件的监测方法，可作为 VAP 监测的补充 |

### 补充七：诊断局限与争议

- **没有无创金标准**：组织病理常被视为金标准，但需要活体组织，临床难以常规获取；实际诊断靠临床、影像与病原学的组合。
- **临床与影像不特异**：新浸润影也可见于肺水肿、ARDS、肺栓塞、肺不张、肺结核等；症候组合只能提高概率，不能单独确诊。
- **病原学方法不统一**：ETA、PSB、BAL 的阈值与准确性不同；培养需 48–72 小时，既往抗菌药物会降低阳性率；ETA 易受上气道定植污染，PSB/BAL 更准确但属侵入性操作。
- **生物标志物只是辅助**：CRP 特异性低，PCT 对诊断的证据有限，sTREM-1、G/GM 试验尚未成为常规依据。
- **CPIS 强度中等**：适合动态评估严重程度与疗程，不宜作为单独确诊工具。

写作提示：报告应说明"临床诊断成立"与"病原学确定"是两件事；培养阴性不能排除 VAP，培养阳性也不能直接等同于感染。
