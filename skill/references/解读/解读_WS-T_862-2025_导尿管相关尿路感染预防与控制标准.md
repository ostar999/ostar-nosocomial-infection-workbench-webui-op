## 1. 判定框架

CAUTI 的判定由三个条件同时成立：

| 条件 | 解读 |
|---|---|
| 导管暴露 | 当前留置导尿管，或拔管后 48 小时内 |
| 尿路感染证据 | 有相应的临床症状/体征，并有病原学或实验室证据支持 |
| 排除其他来源 | 发热等表现不能用其他部位感染解释 |

关键边界：

- **无症状菌尿不等于 CAUTI**。标准明确不宜对留置导尿管患者常规开展无症状菌尿筛查；培养阳性但无感染表现，一般不判定、不治疗。
- **48 小时是拔管后的观察窗**，不是"置管满 48 小时才可能感染"。
- 留置期间出现的尿路感染，需与尿道口定植、污染、肾盂肾炎、盆腔感染等鉴别。

## 2. 留置前的防控（最重要的一步）

| 措施 | 要点 |
|---|---|
| 严格指征 | 非盆腔手术患者、尿失禁患者不宜常规留置；能不用则不用 |
| 术后尽早拔除 | 有指征的手术患者，除病情需要外，术后 24 小时内拔管 |
| 替代方案 | 脊髓损伤/神经源性膀胱可间歇导尿；认知正常、残余尿少的男性可用避孕套导尿 |
| 必要性提醒 | 用电子或书面核查表提醒评估留置必要性 |
| 无菌物品 | 检查导尿包有效期、干燥、包装完整；一次性/复用按规范处理 |
| 导管选择 | 按病情、年龄、性别、尿道情况选型号与材质 |
| 密闭引流 | 使用密闭式引流装置 |
| 患者告知 | 说明目的、配合要点与置管后注意事项 |
| 置管前润滑 | 导尿管涂抹无菌润滑剂 |

## 3. 置管时的防控

- 严格无菌操作，正确铺无菌巾，避免污染尿道口。
- 手卫生后戴无菌手套；动作轻柔，避免损伤尿道黏膜。
- 使用符合要求的皮肤黏膜消毒剂，消毒尿道口及周围。
- 置管中指导患者配合；导管一旦污染，立即更换。

## 4. 留置后的防控

| 类别 | 要点 |
|---|---|
| 固定 | 妥善固定，避免移位、牵拉、打折、弯曲、受压 |
| 位置 | 集尿袋低于膀胱水平，不接触地面，防尿液逆流 |
| 密闭 | 保持引流系统密闭、通畅、完整 |
| 清空 | 使用个人专用或消毒后的容器；出尿口不接触容器 |
| 更换 | 按产品说明更换导尿管与集尿袋；更换集尿袋前先消毒接头再断开 |
| 会阴护理 | 每日温水/皂液清洁尿道口；腹泻或失禁时增加次数，必要时用碘伏消毒 |
| 沐浴 | 保护导尿管，避免浸入水中 |
| 异常更换 | 破损、结晶、引流不畅、阻塞、脱出、污染时及时更换 |
| 症状评估 | 出现尿路感染症状时评估、留尿培养、及时治疗，必要时更换或拔管 |
| 每日评估 | 每天评估留置必要性，不需要时尽早拔除 |
| 长期留置 | 更换频率遵循产品说明 |

### 4.1 不要做的事（标准明确"不应/不宜"）

- 不应为预防 CAUTI 常规用含消毒剂或抗菌药物的溶液做膀胱冲洗或灌注。
- 集尿袋内不应添加抗菌药物或消毒剂。
- 导尿管表面及尿道口不常规局部使用抗菌药物。
- 不应常规使用抗菌药物涂层导尿管。
- 不以预防 CAUTI 为目的常规更换导尿管。
- 不宜常规筛查无症状菌尿。

## 5. 尿液标本采集

| 目的 | 方法 |
|---|---|
| 小量尿标本做微生物检测 | 无菌注射器经导尿管侧面穿刺抽取 |
| 大量尿标本（非细菌/真菌学） | 可从集尿袋采集；不可用打开引流口的方式 |
| 其他 | 按尿液标本微生物检验操作规范执行 |

要点：采样前消毒接口；尽量在抗菌药物使用前采集；注明是否留置导尿管及置管时间。

## 6. 监测指标

- 记录导尿指征、置管时间、置管操作者、拔管时间。
- 统计导尿管使用率、CAUTI 发病率，按风险分层反馈。
- 发生暴发或疑似暴发时，按医院感染暴发处置要求报告与调查。

## 7. 常见判定与防控误区

1. 把无症状菌尿当作 CAUTI，导致不必要的抗菌治疗。
2. 拔管超过 48 小时后发生的尿路感染仍归因于导管。
3. 只凭尿培养阳性、不结合症状与其他感染灶排除。
4. 集尿袋高于膀胱或接触地面，造成逆流。
5. 常规膀胱冲洗"预防"感染，反而增加污染与耐药。
6. 常规更换导尿管或使用抗菌涂层导管，缺乏指征。
7. 采样时打开引流口取尿，污染样本。
8. 留置必要性未每日评估，导管留置时间过长。

## 8. 与工作台评分条目的对应

| 评分层 | 对应事实 |
|---|---|
| 导管暴露 gate | 留置中/拔管 48 小时内；置管与拔管日期 |
| 临床层 | 发热、尿路刺激征、腰痛、耻骨上压痛等 |
| 病原学层 | 尿培养结果、采样方式、是否抗菌药物使用前 |
| 排除项 | 无症状菌尿、污染、其他部位感染、尿道口定植 |
| 防控核查 | 指征、密闭引流、集尿袋位置、每日评估、是否常规冲洗 |

## 补充：定义分层、鉴别与实施细节

### 补充一：定义分层

| 维度 | 类型 | 说明 |
|---|---|---|
| 部位 | 上尿路 | 肾盂肾炎、输尿管炎 |
| 部位 | 下尿路 | 膀胱炎、尿道炎 |
| 尿路状态 | 复杂性 | 有梗阻、结石、畸形、反流等异常 |
| 尿路状态 | 非复杂性 | 无上述异常 |
| 导管相关 | CAUTI | 留置期间或拔管后 48 小时内发生 |

### 补充二：临床识别

留置导尿管患者的尿路感染表现常不典型：发热、寒战、腰痛、肋脊角叩痛、耻骨上压痛、尿液浑浊或异味；老年患者可能仅表现为意识改变或乏力。不能仅凭尿液浑浊或气味诊断。

### 补充三：鉴别

| 情况 | 与 CAUTI 的区别 |
|---|---|
| 无症状菌尿 | 培养阳性但无感染表现；不主动筛查、不常规治疗 |
| 污染 | 采样不规范、接口污染；重复培养与采样方式可帮助判断 |
| 尿道口定植 | 局部定植，无全身感染证据 |
| 其他感染源 | 肺部、腹腔、导管相关血流感染、肾盂肾炎等 |
| 非感染性血尿/结晶 | 无感染表现，尿检以红细胞/结晶为主 |

### 补充四：实施细节

- 导尿管型号与材质按患者情况选择；不常规用抗菌涂层。
- 集尿袋按产品说明更换；更换前先消毒接头再断开。
- 尿道口每日温水/皂液清洁；腹泻或失禁时增加频次。
- 采样：小量标本经导管侧面无菌穿刺；大量标本从集尿袋取，但不用于细菌/真菌学。
- 每日评估留置必要性；出现症状时先留标本再治疗。

### 补充五：监测指标

- 导尿管使用率、CAUTI 发病率、病原谱。
- 置管指征符合率、每日评估执行率、集尿袋位置合格率。

### 补充六：诊断局限

- **本标准不含完整诊断阈值**：862 只给定义与防控要求；临床与病原学诊断需回到 2001、187 号与专项指南。
- **症状常不典型**：留置导尿患者可能只有发热、意识改变或乏力；尿液浑浊、异味不能作为诊断依据。
- **无症状菌尿常见**：培养阳性但无感染表现时，多为菌尿症或定植，不等同于 CAUTI。
- **培养受采样影响**：集尿袋取样、接口污染、多菌生长、近期抗菌药物都会影响结果；应尽量经导管侧面无菌穿刺并在用药前留取。
- **48 小时是定义边界**：拔管后超过 48 小时发生的感染不再归因于导管，但仍需按其他尿路感染判断。

写作提示：报告要写清"导管暴露时间 + 症状 + 尿检/培养 + 是否排除其他感染源"，不要只凭培养阳性下结论。

| 监测 | 按 WS/T 312 开展目标性监测，持续质量改进 |
| 培训 | 导尿操作、无菌技术、留置维护、CAUTI 防控、替代方案 |
| 风险评估 | 评估患者 CAUTI 风险，针对高危因素落实措施 |
| 手卫生 | 留置与维护时按 WS/T 313 执行 |
| 监测记录 | 记录导尿指征、置管时间、操作者、拔管时间；统计使用率与发病率 |
