## 0. 三个术语先分清

CLABSI、CRBSI、VCAI 说的不是同一件事，混用会直接影响判定与报告。

| 术语（全称） | 定义要点 | 主要用途 | 注意 |
|---|---|---|---|
| **CLABSI**（Central Line-Associated Bloodstream Infection，中央导管相关血流感染） | 留置中央导管期间或拔管后 48 小时内发生的原发性血流感染，且与其他部位感染无关；相关标准和文献未强制要求导管尖端培养 | 监测（发病率、质量指标）与临床诊断均可，监测场景最常用 | 定义范围较宽；不能简化成“只算发病率”，也不能说“不要求导管尖端培养” |
| **CRBSI**（Catheter-Related Bloodstream Infection，导管相关血流感染） | 有血流感染，并有证据表明导管是来源：导管段与外周血同种同药敏、差异阳性时间≥2 小时、导管血定量≥外周血 5 倍等；同时排除其他感染源 | 临床归因诊断；也可用于监测/质量评价 | 比 CLABSI 严格，需要病原学归因证据；不意味着只能用于临床 |
| **VCAI**（Vascular Catheter-Associated Infection，血管导管相关感染） | 留置血管导管期间或拔管后 48 小时内发生的原发性、与其他部位感染无关的感染，**包括局部感染与血流感染** | 国内院感判定、防控与上报；也可用于监测与临床诊断 | 范围比 CLABSI/CRBSI 宽；只有其中的血流感染部分才与前两者对应 |

三者关系可以记成：

- **VCAI 范围最宽**：局部感染 + 血流感染；
- **CLABSI 常用于监测**：可用于回答“这家医院/这个科室的导管相关血流感染率是多少（ICU、普通病房、血透中心等均适用）”，2025 指南也把它作为有临床诊断意义的排他性诊断；
- **CRBSI 强调临床归因**：回答“这个患者的血流感染是不是导管引起的、要不要拔管、用多久药”，也可用于监测/质量评价。

> **用词提醒**：相关标准和文献**未强制要求**做导管尖端培养，不等于“不要求”。导管尖端培养、差异阳性时间、导管血定量培养等证据越多，对诊断 CLABSI 的支持越强。

**三者都同时具备发病率监测与临床诊断意义；没有标准或文献否定任一定义的监测或临床价值。** 这三种定义都可**用于任何科室**（ICU、普通病房、血透中心等）的发病率监测、临床诊断与质量指标监控，**不与 ICU 或某一科室绑定**；选择取决于使用目的和定义的严格程度，而不是科室。实际工作中按场景选择定义。

因此：

- 做目标性监测、算发病率，或按 2025 指南做临床排他性判断 → 常用 **CLABSI**；
- 临床诊断、决定拔管与疗程 → 用 **CRBSI**；
- 按国内指南做院感判定、写“血管导管相关感染” → 用 **VCAI**；
- 引用 2025 指南时，按原文使用 **CLABSI** 表述，并在报告中注明它强调排他性诊断，不要自行改写成 CRBSI。

## 1. 判定框架

CLABSI 的判定由四个要素组成，缺一不可：

| 要素 | 内容 | 常见错误 |
|---|---|---|
| 时间 | 导管留置期间，或拔管后 48 小时内 | 把拔管一周后的菌血症算作导管相关 |
| 临床表现 | 发热（>38℃）、寒颤、低血压等脓毒症表现 | 仅凭培养阳性、无任何临床征象即上报 |
| 感染源 | 除血管内导管外，找不到其他明确感染源 | 不排查肺部、腹腔、尿路、心内膜炎等 |
| 微生物证据 | 外周静脉血培养阳性；或导管段与外周血培养出同种、同药敏病原体 | 只送导管血、不做外周血对照 |

因此它是**排除性诊断**：先确认"有血流感染"，再确认"导管是最可能来源"，最后排除其他来源。

## 2. 标本采集（决定诊断上限）

| 项目 | 规范做法 | 说明 |
|---|---|---|
| 套数与瓶数 | 两套四瓶（需氧、厌氧各一套） | 一套经皮外周静脉，一套经导管接头或输液港 |
| 采血时机 | 两套尽量同一时间采集 | 分别标记"外周/导管"，否则无法比较 |
| 采血量 | 每瓶 8–10 mL | 过少易假阴性，过多可因白细胞产气出现假阳性 |
| 送检时限 | 采集后 2 小时内送检，最迟不超过 4 小时 | 室温运送；延迟时室温保存 |
| 导管尖端 | 拔管时无菌剪取约 5 cm，干燥无菌容器送检，Maki 半定量法 | 港体储液器一并送检可提高准确性 |
| 多腔导管 | 每个腔分别留取 | 只留一腔可能漏检 |
| 局部感染 | 脓性分泌物/渗液做革兰染色与培养，同时留外周血 | 穿刺点 2 cm 内红、硬、热、痛或脓性分泌物提示局部感染 |

血培养污染率约 3%–5%，阳性结果必须结合临床与检验指标判断，不能单独作为诊断依据。

## 3. 微生物学诊断

- 血培养仍是金标准；分子生物学方法（核酸扩增、测序、质谱等）可提高检出率，但阳性结果同样需要结合临床判断是否为致病菌。
- 诊断路径：
  1. 外周血培养阳性 + 符合临床表现 + 无其他感染源 → 可诊断；
  2. 导管段与外周血培养同种、同药敏 → 支持导管为来源；
  3. 仅导管血阳性、外周血阴性 → 不足以诊断，需考虑导管定植或采血污染。
- 差异阳性时间（DTP）等辅助方法依赖采血方式与实验室流程，可作为参考，不宜单独作为判定依据。

## 4. 高危因素与临床线索

| 类别 | 具体因素 |
|---|---|
| 导管因素 | 股静脉/股动静脉置管、多腔导管、留置时间长、紧急置管、非隧道式导管、既往 CLABSI 史 |
| 宿主因素 | 中性粒细胞减少、血液系统恶性肿瘤、实体器官或骨髓移植、严重免疫抑制、ICU 住院时间长 |
| 治疗因素 | 全肠外营养、长期广谱抗菌药物、多个部位念珠菌定植、股动静脉置管 |
| 局部线索 | 穿刺点红肿热痛或脓性分泌物；隧道/囊袋感染范围可超过穿刺点 2 cm，伴皮肤坏死 |

## 5. 处理原则

### 5.1 导管去留

- 疑诊 CLABSI 时**尽早拔管**是基本策略：拔管可显著降低病死率，革兰阴性杆菌与念珠菌相关感染获益更明显；48 小时内拔管与预后改善相关。
- **珍贵导管**（儿科、烧伤、ECMO、无处可置管等）需个体化权衡：重新置管风险、保留导管治愈可能性、治疗失败代价。保留导管者应评估封管/抗菌锁治疗与密切随访。

### 5.2 经验性抗菌治疗

| 场景 | 是否覆盖 | 常用选择 |
|---|---|---|
| 合并脓毒性休克 | 覆盖革兰阳性球菌 | 万古霉素等糖肽类，或按当地 MRSA 流行病学选择 |
| 血流动力学不稳定、中性粒细胞减少、血液肿瘤/移植、股静脉置管、革兰阴性杆菌定植、ICU 长期住院 | 覆盖革兰阴性杆菌 | 第四代头孢、β-内酰胺酶抑制剂合剂或碳青霉烯类；有 ESBL 风险者避免氨曲南与头孢菌素单用 |
| 念珠菌高危（股静脉、TPN、多部位定植、腹部手术、长期广谱抗菌药）且合并休克 | 可经验性覆盖念珠菌 | 棘白菌素；近 3 个月未用过氟康唑者可考虑氟康唑 |

### 5.3 目标治疗

| 病原 | 首选/推荐 | 备注 |
|---|---|---|
| MSSA | 氯唑西林或头孢唑林 | β-内酰胺过敏可用达托霉素或糖肽类；不推荐万古霉素作为 MSSA 首选 |
| MRSA | 糖肽类（万古霉素等）或头孢比罗 | 按药敏与病情选择 |
| 甲氧西林敏感 CoNS | 氯唑西林或头孢唑林 | — |
| 甲氧西林耐药 CoNS | 糖肽类 | — |
| 肠球菌 | 氨苄西林（敏感株）；耐药或过敏用糖肽类 | 需超声心动图排除感染性心内膜炎 |
| 革兰阴性杆菌 | 按药敏选择 | 哌拉西林他唑巴坦与碳青霉烯类在病死率上无显著差异 |
| CRPA / DTR-PA | 按药敏；DTR-PA 可用头孢洛扎-他唑巴坦 | — |
| CRAB | 以舒巴坦制剂为基础，联合多黏菌素或替加环素 | — |
| CRKP | 黏菌素联合替加环素 | 产碳青霉烯酶者可考虑头孢他啶-阿维巴坦 |
| 念珠菌 | 棘白菌素 | 无法拔管者可选用对生物膜有活性的药物；两性霉素 B 脂质体用于耐药株 |

### 5.4 疗程

| 病原 | 疗程 |
|---|---|
| MRSA | 血培养转阴后 14 天 |
| 革兰阴性杆菌 | 7–14 天 |
| 非复杂念珠菌血症 | 首次血培养阴性后至少 14 天 |
| 复杂感染（心内膜炎、化脓性血栓性静脉炎、深部脓肿） | 个体化延长，并请专科会诊 |

## 6. 预防要点（核对清单）

**置管环节**

- 严格掌握指征，能不用则不用；优先选择上肢/锁骨下等部位，尽量避免股静脉。
- 最大无菌屏障（帽子、口罩、无菌衣、无菌手套、全身铺巾）。
- 皮肤消毒首选氯己定-酒精；超声引导提高成功率、减少反复穿刺。
- 减少管腔数；按需选择抗菌涂层导管；不常规定期更换导管，也不常规经导丝原位更换。

**维护环节**

- 敷料：无菌透明敷料或纱布，按渗液/污染情况更换；局部抗菌敷料可用于高危患者。
- 接头：无针接头每次使用前规范消毒（擦洗并待干）；按厂家/规范更换输液接头与管路。
- 每日评估导管必要性，尽早拔除；不常规经中心导管采血。
- 不常规使用抗菌溶液封管；氯己定全身擦浴可用于高危 ICU 患者。
- 手卫生、无菌操作、集束化核查表是基础。

## 7. 判定与评分中的常见误区

1. 只送导管血、不送外周血，无法判断感染源。
2. 单套培养阳性即诊断，忽略污染与定植。
3. 不排查其他感染源（肺部、腹腔、尿路、心内膜炎），把"导管相关"当默认结论。
4. 拔管不及时，尤其在休克、革兰阴性杆菌或念珠菌感染时。
5. 疗程"宁长勿短"，增加耐药与毒性；或过早停药导致复发。
6. 把导管定植、穿刺点局部感染与 CLABSI 混为一谈。
7. 对念珠菌过度经验性覆盖，或反之延误治疗。

## 补充：预防细节、特殊导管与鉴别

### 补充一：预防细节

| 环节 | 要点 |
|---|---|
| 指征 | 严格掌握，能不用则不用；每日评估，尽早拔除 |
| 部位 | 优先上肢/锁骨下等部位，避免股静脉；透析、ECMO 等按专项考虑 |
| 屏障 | 最大无菌屏障 |
| 皮肤消毒 | 氯己定-酒精，按产品说明作用时间 |
| 置管 | 超声引导，减少反复穿刺 |
| 管腔 | 尽可能少 |
| 敷料 | 无菌透明或纱布，渗液/污染时更换；高危可用抗菌敷料 |
| 接头 | 每次使用前规范消毒，待干 |
| 输液装置 | 按规范更换；不常规经导管采血 |
| 封管 | 不常规抗菌封管；仅特定高危/无法拔管者考虑 |
| 擦浴 | 高危 ICU 可考虑氯己定擦浴 |
| 更换 | 不常规定期更换 CVC；疑诊感染时拔管而非导丝更换 |

### 补充二：特殊导管

- 透析导管：隧道式/带 cuff 导管与临时导管的风险不同；置管部位与维护按透析通路要求。
- ECMO 导管：管路粗、留置时间长，感染风险高；每日评估、严格无菌、尽早撤机。
- PICC：优先选择合适静脉，避免不必要的多腔；维护与接头消毒同样关键。

### 补充三：鉴别

| 情况 | 与 CLABSI 的区别 |
|---|---|
| 其他部位血流感染 | 肺部、腹腔、尿路、心内膜炎等；需找原发灶 |
| 污染 | 皮肤菌群（尤其 CoNS）污染；需重复培养与临床判断 |
| 导管定植 | 导管段培养阳性但无血流感染表现 |
| 感染性心内膜炎 | 持续菌血症、心脏杂音、超声赘生物 |
| 化脓性血栓性静脉炎 | 局部疼痛、肿胀、菌血症 |

### 补充四：疗程与高危因素

- MRSA：血培养转阴后 14 天；革兰阴性杆菌 7–14 天；念珠菌首次阴性后至少 14 天；复杂感染延长。
- 高危因素：股静脉、长期留置、多腔、TPN、中性粒细胞减少、血液肿瘤/移植、多部位念珠菌定植、ICU 长期住院、长期广谱抗菌药。

### 补充五：诊断局限与争议

- **排他性诊断**：CLABSI 没有单一确诊试验，必须排除导管以外的感染源；临床与微生物证据要一起看。
- **血培养是金标准但有限制**：培养需时间，污染率约 3%–5%，既往抗菌药物会降低阳性率；单次阳性需结合临床与重复培养。
- **导管尖端培养不等于血流感染**：尖端阳性可能只是定植；只有与外周血同种同药敏时，支持力度才更强。
- **辅助方法未统一**：差异阳性时间、分子检测等受采血方式与实验室流程影响，不能单独作为判定依据。
- **保留导管时更难判断**：局部表现非特异，需结合影像、超声心动图与随访血培养。

写作提示：报告应分别写"临床诊断是否成立""病原学符合程度""是否排除其他感染源"，把不确定性放进信息缺口。

### 补充六：预防推荐细节

| 环节 | 要点 |
|---|---|
| CVC 部位 | 锁骨下静脉为首选；尽量避免股静脉 |
| 血液净化导管 | 首选右侧颈内静脉，其次股静脉 |
| ECMO 导管 | VA-ECMO 首选股动/静脉；VV-ECMO 选右股静脉-右颈内静脉，单管双腔首选右颈内静脉；VVA/VAV 选右股静脉、右颈内静脉/左股动脉 |
| PICC 部位 | 贵要静脉为首选 |
| 导管材质 | 聚氨酯或硅橡胶；长期留置选硅橡胶 |
| 抗菌涂层 | 推荐带抗菌涂层的 CVC（弱推荐，高质量证据） |
| 管腔 | 满足诊疗需要的最少腔数 |
| 屏障与消毒 | 最大无菌屏障；含醇氯己定皮肤消毒 |
| 置管 | 常规超声引导 |
| 敷料 | 无菌透明敷料；纱布每 2 天、透明敷料每 7 天更换；松动/潮湿/污染/破损随时更换；高危可用氯己定抗菌敷料 |
