## 1. 判定框架：时间窗 + 解剖层次 + 植入物

术后切口或深部组织的感染是否计入 SSI，先看三个变量：

| 变量 | 作用 |
|---|---|
| 时间窗 | 表浅切口 30 天；深部/器官腔隙在无植入物时 30 天，有植入物时 90 天 |
| 解剖层次 | 仅皮肤皮下 = 表浅；深筋膜与肌肉 = 深部；器官或腔隙 = 器官/腔隙 |
| 植入物 | 人工瓣膜、人造血管、人工关节等植入物会把深部/器官腔隙的观察窗延长到 90 天 |

### 1.1 三类 SSI 的边界

| 类型 | 时间窗 | 累及范围 | 判定提示 |
|---|---|---|---|
| 表浅切口感染 | 术后 30 天内 | 仅切口皮肤与皮下组织 | 红、肿、热、痛、脓性分泌物，或培养阳性 |
| 深部切口感染 | 无植入物 30 天内；有植入物 90 天内 | 深筋膜与肌肉 | 深部脓液、脓肿、切口裂开、发热等 |
| 器官/腔隙感染 | 无植入物 30 天内；有植入物 90 天内 | 皮肤、皮下、深筋膜、肌肉以外的器官或腔隙 | 如腹腔脓肿、脑脓肿、脓胸、关节腔感染等 |

注意：时间窗从手术当日算起；超过窗口的感染不按 SSI 统计，但仍需按其他医院感染类型判断。

### 1.2 切口分类（决定风险与预防用药）

| 类别 | 含义 | 举例 |
|---|---|---|
| Ⅰ 类（清洁） | 手术部位为无菌区域，未进入呼吸道、消化道、泌尿生殖道等有菌腔道 | 甲状腺手术、单纯疝修补 |
| Ⅱ 类（清洁-污染） | 手术进入有菌腔道但无明显溢出 | 经口咽手术、子宫全切、择期胃肠道手术 |
| Ⅲ 类（污染） | 有明显污染或急性炎症但未化脓 | 胃肠道内容物溢出、新鲜开放性创伤未及时清创 |
| Ⅳ 类（感染） | 已有临床感染、脏器穿孔或失活组织的陈旧创伤 | 化脓性阑尾炎穿孔、感染切口手术 |

## 2. 判定要点

1. **先看切口层次**：表浅感染不能写成深部感染；深部感染需有深筋膜/肌肉受累证据。
2. **再看植入物**：有植入物者把深部/器官腔隙窗口延长至 90 天，不能按 30 天截断。
3. **证据组合**：局部症状体征 + 脓性分泌物/脓肿 + 病原学或影像证据；单纯切口红肿需与缝线反应、脂肪液化、药物过敏鉴别。
4. **标本质量决定判定**：怀疑感染时应在抗菌药物使用前采样，优先取组织或脓液，而不是仅取拭子；送检时注明部位与手术日期。
5. **与器官/腔隙感染区分**：腹腔脓肿、吻合口漏导致的腹腔感染属于器官/腔隙感染，不是表浅切口感染。

## 3. 围手术期预防（按时间轴）

### 3.1 术前

| 措施 | 要点 |
|---|---|
| 缩短术前住院 | 减少院内定植与耐药菌暴露 |
| 血糖管理 | 围手术期将血糖控制在合理范围，尤其糖尿病患者 |
| 戒烟 | 择期手术前戒烟，降低切口并发症 |
| 结直肠手术 | 成年患者可口服抗菌药物联合机械性肠道准备 |
| 治疗远处感染 | 手术部位以外的活动性感染，宜先控制再择期手术 |
| 清洁 | 术前沐浴、清洁手术部位、更换清洁衣物 |
| 备皮 | 不影响操作时不剃毛；必须去除时用不损伤皮肤的方式，临近手术时进行 |
| 皮肤消毒 | 以切口为中心，清洁/清洁-污染切口由内向外，污染/感染切口由外向内，范围足够大 |

### 3.2 术中

| 措施 | 要点 |
|---|---|
| 手术排序 | 按感染风险由清洁到污染安排；洁净手术间遵循相应规范 |
| 人员与气流 | 限制进入人数，保持手术间正压、回风口通畅、门关闭 |
| 器械 | 复用器械按清洗消毒灭菌规范处理 |
| 着装 | 刷手服、帽子、外科口罩；参与手术者无菌手术衣与无菌手套 |
| 无菌技术 | 药品与无菌溶液一台一用；减少创伤、彻底止血、清除坏死组织与异物、消灭死腔 |
| 污染处理 | 严重污染时可延期缝合或旷置；引流管尽量另戳孔、优先闭合引流，不作为延长预防用药的理由 |
| 体温 | 核心体温不低于 36℃，冲洗液/输血/输液加温至约 37℃ |
| 氧合 | 全麻插管且肺功能正常者，术中或拔管后提高吸入氧浓度 |
| 环境 | 每台术后清洁消毒手术台及周边区域，污染时随时处理 |

### 3.3 术后

- 换药前后、接触手术部位前后执行手卫生；换药遵循无菌操作。
- 保持敷料干燥，渗湿及时更换；加强引流管管理，尽早拔除。
- 观察出血、感染征象；出院患者定期随访切口愈合情况。
- 怀疑与环境因素相关时开展环境微生物学监测；暴发按暴发处置规范调查。

### 3.4 预防用药

- 目的是预防手术部位感染，不覆盖与手术无关的术后其他部位感染。
- 品种与用法遵循《抗菌药物临床应用指导原则》；不因留置引流管而延长预防用药。

## 4. 标本采集（附录要点）

| 环节 | 要点 |
|---|---|
| 时机 | 抗菌药物使用前采集 |
| 方法 | 无菌操作；闭合性脓肿穿刺抽取脓液；开放性伤口先清洁表面，再取深部组织/脓液 |
| 容器 | 无菌、干燥、密闭，避免拭子替代组织/液体 |
| 标识 | 注明患者、部位、手术日期、标本类型 |
| 送检 | 及时送检，厌氧培养需相应转运条件 |

## 5. 监测与质量指标

- 按医院感染监测规范开展 SSI 目标性监测，记录手术类型、切口等级、植入物、手术时长、失血、血糖、体温等风险因素。
- 指标包括 SSI 发病率、不同切口等级的感染率、病原谱与耐药性、预防用药依从性。
- 监测结果定期反馈到手术科室，用于改进围手术期流程。

## 6. 常见判定误区

1. 把术后 30 天后的深部感染直接排除，忽略植入物的 90 天窗口。
2. 把表浅切口感染写成深部感染，或反之；未核对深筋膜/肌肉受累证据。
3. 把缝线反应、脂肪液化、药物疹当作 SSI。
4. 只送拭子、不做组织/脓液培养，病原学证据不足。
5. 在抗菌药物使用后才采样，培养阴性不能排除感染。
6. 把器官/腔隙感染误归为切口感染，影响分类统计。
7. 以"预防用药未停"解释持续发热，忽略脓肿/深部感染评估。

## 7. 与工作台评分条目的对应

| 评分层 | 对应事实 |
|---|---|
| 时间窗 gate | 手术日期、感染日期、30/90 天窗口、植入物 |
| 部位层次 | 表浅/深部/器官腔隙；深筋膜、肌肉、器官受累证据 |
| 微生物证据 | 脓液/组织培养、涂片、影像（脓肿） |
| 危险因素 | 切口等级、手术时长、失血、血糖、体温、植入物 |
| 排除项 | 缝线反应、脂肪液化、非感染性积液、其他部位感染 |

## 补充：临床识别、危险因素与鉴别

### 补充一：SSI 的临床识别

| 表现 | 提示 |
|---|---|
| 切口脓性分泌物 | 表浅或深部感染的重要线索；需与缝线反应鉴别 |
| 局部红、肿、热、痛或压痛 | 关注范围、进展速度、有无波动感 |
| 发热 | 不一定出现；深部/器官腔隙感染更常见 |
| 切口裂开 | 感染性裂开需与机械性裂开、脂肪液化鉴别 |
| 脓肿或影像积液 | 深部/器官腔隙感染的证据 |
| 病原学阳性 | 需结合采样质量与临床表现 |

### 补充二：常见危险因素

| 类别 | 因素 |
|---|---|
| 患者 | 高龄、糖尿病、肥胖、吸烟、免疫抑制、营养不良、术前定植、远处感染 |
| 手术 | 切口等级、手术时长、失血与输血、急诊手术、植入物、操作技巧与死腔 |
| 术后 | 切口污染、敷料潮湿、引流管理不当、血糖控制不佳 |

### 补充三：鉴别

- 缝线反应：局限于缝线处，拆除后很快消退，无脓性分泌物。
- 脂肪液化：切口渗液呈油性，无脓性、无明显红肿热痛，培养多阴性。
- 血清肿/血肿：肿胀波动感，穿刺为血清或血液，非脓性。
- 非感染性裂开：切口裂开但无感染征象。
- 药物疹/过敏：与用药时间相关，常伴瘙痒、皮疹。
- 深部脓肿：需影像与穿刺证实，不能仅凭切口外观排除。

### 补充四：监测指标

- SSI 发病率、按切口等级分层感染率、病原谱与耐药性。
- 围手术期预防用药依从性、血糖与体温管理达标率。
- 出院后随访：植入物手术需覆盖 90 天窗口。

### 补充五：诊断局限

- **没有单一确诊试验**：SSI 依赖局部表现、脓性分泌物、培养与影像/手术探查的组合；培养阴性不能排除感染。
- **层次判断可能模糊**：表浅、深部与器官/腔隙感染的界限，有时需影像、穿刺或再次手术才能确定。
- **时间窗口径不一**：有植入物者，《WS/T 861-2025 手术部位感染预防与控制标准》为 90 天，《卫医发[2001]2号 医院感染诊断标准（试行）》与《卫办医政发〔2010〕187号 外科手术部位感染预防与控制技术指南（试行）》为 1 年；同一病例可能因口径不同得出不同结论。
- **易与术后正常反应混淆**：缝线反应、脂肪液化、血清肿、血肿、非感染性裂开都可表现为切口异常。

写作提示：报告应注明采用的时限口径与证据强度；不能仅凭切口外观判定深部感染。

### 补充六：管理要求与暴发处置

| 层级 | 要求 |
|---|---|
| 医疗机构 | 将 SSI 防控纳入医疗质量管理；制定制度与标准操作规程；按 WS/T 312 开展监测；手卫生按 WS/T 313 |
| 手术部（室） | 建筑符合 GB 50333；建立清洁消毒、隔离、MDRO/特殊病原体手术管理、手卫生、培训等制度；保持环境清洁并定期消毒 |
| 相关临床科室 | 知晓本科室 SSI 情况并培训；对患者/家属宣教；病区环境按 WS/T 512 清洁消毒；怀疑感染时按附录 A 采样并及时报告 |
| 暴发处置 | 按 WS/T 524 开展流行病学调查、分析与控制；重点查找与分析相关因素；怀疑环境因素时做环境微生物学监测 |

> 围手术期预防用药的目的仅是预防 SSI，品种与用法遵循《抗菌药物临床应用指导原则》；不因留置引流管而延长预防用药。
