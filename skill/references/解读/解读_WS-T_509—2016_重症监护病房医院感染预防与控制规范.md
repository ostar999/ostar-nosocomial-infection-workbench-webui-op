## 1. 组织与制度

| 要求 | 要点 |
|---|---|
| 管理小组 | 由科主任、护士长与兼职感控人员组成，负责本科室感控工作 |
| 制度与 SOP | 制定并持续完善，落实到诊疗护理 |
| 问题改进 | 定期研究感控问题与改进方案 |
| 督查反馈 | 感控专职人员督查措施落实，记录并反馈 |
| 培训 | 医生、护士、进修/实习、保洁等全员接受感控培训 |
| 抗菌药物 | 应用与管理遵循国家法规与指导原则 |
| 医疗废物 | 按医疗废物管理法规分类处置 |
| 家属宣教 | 向家属说明感控规定 |

## 2. 布局与设施

| 项目 | 要求 |
|---|---|
| 位置 | 便于患者转运、检查与治疗 |
| 分区 | 洁污分开，医疗区、辅助用房区、污物处理区相对独立 |
| 床单元面积 | 不少于 15 m² |
| 床间距 | 大于 1 m |
| 单间 | 至少 1 间，使用面积不少于 18 m² |
| 通风采光 | 良好 |
| 温度 | 24℃ ± 1.5℃ |
| 湿度 | 30%–60% |
| 装修 | 防潮防霉、耐腐蚀、防静电、不易产尘积尘、便于清洁消毒 |
| 植物 | 室内不摆放干花、鲜花或盆栽 |

## 3. 人员与隔离

| 类别 | 要点 |
|---|---|
| 人员配置 | 足够数量、受过训练；护士与实际床位数之比不低于 3:1 |
| MDRO 护理 | 宜分组、人员相对固定 |
| 带病上岗 | 患呼吸道感染、腹泻等感染性疾病者避免直接接触患者 |
| 标准预防 | 按隔离技术规范执行；配备足量防护用品 |
| 分区安置 | 感染、疑似感染、非感染患者分区 |
| 传播途径隔离 | 在标准预防基础上按接触/飞沫/空气传播采取措施 |
| MDRO 隔离 | 宜单间；不足时同类集中安置并标识 |
| 探视 | 明示时间、限制人数、专床专用探视服；呼吸道感染者谢绝探视 |

## 4. 监测

- 常规监测发病率、感染部位构成、病原微生物，方法遵循医院感染监测规范。
- 开展目标性监测：VAP、CLABSI、CAUTI、MDRO；疑似感染者留取标本做微生物与药敏。
- 早期识别暴发：报告制度、流行病学调查、同源性鉴定（必要时）。
- 每季度监测物体表面、医务人员手、空气的消毒效果；暴发、新建/改建、消毒方法改变时随时监测。
- 汇总分析趋势与危险因素，反馈并改进；宜用信息系统。

## 5. 三管相关感染防控

### 5.1 中央导管相关血流感染（CLABSI）

| 措施 | 要点 |
|---|---|
| 指征与评估 | 严格掌握指征，每日评估必要性，尽早拔除 |
| 置管 | 无菌操作，最大无菌屏障 |
| 皮肤消毒 | 宜用有效浓度 ≥2 g/L 氯己定-乙醇（70% 乙醇）擦拭 2–3 遍，按产品说明作用时间 |
| 导管选择 | 尽可能选腔数较少的导管 |
| 部位 | 不宜选择股静脉 |
| 维护 | 保持穿刺点干燥，观察感染征象 |
| 更换 | 无感染征象时不常规更换；不定期对穿刺点涂抹送检 |
| 疑似感染 | 无禁忌时立即拔管，导管尖端与静脉血送检 |

### 5.2 导尿管相关尿路感染（CAUTI）

| 措施 | 要点 |
|---|---|
| 指征与评估 | 严格掌握指征，每日评估，尽早拔除 |
| 置管 | 严格无菌操作 |
| 夹闭训练 | 置管超过 3 天者，宜持续夹闭、定时开放 |
| 引流系统 | 保持密闭，不常规膀胱冲洗 |
| 维护 | 防滑脱，保持尿道口及会阴清洁 |
| 集尿袋 | 低于膀胱水平，防反流 |
| 更换 | 长期留置者定期更换：普通导尿管 7–10 天，特殊类型按说明；更换导尿管同时更换集尿袋 |
| 采样 | 微生物检测经导尿管侧面无菌穿刺抽取；其他目的从集尿袋开口采集 |

### 5.3 呼吸机相关肺炎（VAP）

| 措施 | 要点 |
|---|---|
| 每日评估 | 评估呼吸机与气管插管必要性，尽早脱机/拔管 |
| 体位 | 无禁忌时头胸部抬高 30°–45°，协助翻身拍背、震动排痰 |
| 口腔护理 | 使用有消毒作用的口腔含漱液，每 6–8 小时一次 |
| 气道操作 | 严格无菌 |
| 插管路径 | 宜经口 |
| 气管切开 | 保持局部清洁干燥 |
| 声门下 | 宜用气囊上方带侧腔的导管，及时清除声门下分泌物 |
| 气囊放气/拔管 | 先确认气囊上方分泌物已清除 |
| 湿化 | 湿化液用无菌水 |
| 管路消毒 | 内外管路按规范清洁消毒 |
| 镇静 | 每日评估镇静必要性，尽早停用 |

## 6. 手卫生

- 配备足够的非手触式洗手设施与速干手消毒剂；洗手设施与床位数之比不低于 1:2，单间每床 1 套。
- 使用一次性包装皂液；每床配备速干手消毒剂；干手宜用一次性纸巾。
- 医务人员执行手卫生规范；探视者进入前后洗手或用手消毒剂。

## 7. 环境清洁消毒

| 对象 | 要求 |
|---|---|
| 物体表面 | 保持清洁；污染随时清洁消毒；医疗区域每天 1–2 次，达到中水平消毒 |
| 键盘 | 宜覆保护膜，表面每天 1–2 次 |
| 一般诊疗器械 | 宜专床专用；交叉使用一用一消毒 |
| 持续使用设备 | 监护仪、输液泵、氧气流量表等表面每天 1–2 次 |
| 交叉使用设备 | 直接接触患者部分每人用后立即清洁消毒；非接触部分每周 1–2 次 |
| MDRO 患者器械 | 专人专用或一用一消毒 |
| 地面 | 每天 1–2 次 |
| 空气净化系统 | 出/回风口每周 1–2 次 |
| 呼吸机 | 外壳面板每天 1–2 次；外部管路一人一用一消毒/灭菌，长期使用者每周更换；内部管路按厂家说明 |
| 床单元 | 患者转出/出院/死亡后终末清洁消毒 |
| 便器 | 专人专用，按规范清洗消毒 |
| 空气消毒 | 按规范执行，通风为主，必要时空气消毒 |

## 8. 常见误区

1. 床单元面积、床间距、单间面积不达标，却只关注消毒剂。
2. 护士配置不足，导致手卫生与导管维护依从性下降。
3. MDRO 患者未单间或集中安置，隔离标识不清。
4. 只做终末消毒，忽略每日 1–2 次的表面清洁消毒。
5. 导尿管留置超过 3 天仍持续开放引流，未做夹闭训练。
6. 常规膀胱冲洗或穿刺点涂抹送检。
7. 呼吸机管路频繁更换，或湿化液用非无菌水。
8. 口腔护理频次不足，或未使用有消毒作用的含漱液。
9. 镇静未每日评估，脱机延迟。

## 9. 与工作台评分条目的对应

| 评分层 | 对应事实 |
|---|---|
| ICU 暴露 | 入住 ICU、床单元/单间条件、住院时长 |
| 器械 gate | 中央导管、导尿管、呼吸机的留置与拔除时间 |
| 防控核查 | 每日评估、最大无菌屏障、氯己定消毒、集尿袋位置、床头角度、气囊压力、口腔护理 |
| 环境/人员 | 手卫生设施、隔离措施、环境清洁频次、MDRO 管理 |
| 监测 | 目标性监测、暴发识别、消毒效果监测 |

## 补充：环境、手卫生与监测细节

### 补充一：环境清洁

| 对象 | 要点 |
|---|---|
| 床单元 | 患者转出、出院或死亡后终末清洁消毒；床栏、床头桌、呼叫按钮每日清洁消毒 |
| 便器 | 专人专用，按规范清洗消毒；不得混用 |
| 隔帘 | 保持清洁干燥；污染及时更换；MDRO 患者使用后终末消毒 |
| 空气 | 以通风为主；必要时按规范消毒；空气净化系统出/回风口每周清洁消毒 |
| 清洁工具 | 分区使用，用后清洗消毒，避免交叉污染 |

### 补充二：手卫生

- 洗手设施与床位数比例不低于 1:2；单间每床 1 套。
- 每床配备速干手消毒剂；使用一次性包装皂液与一次性干手纸巾。
- 接触患者前后、无菌操作前、接触体液后、接触患者周围环境后执行手卫生。
- 探视者进入前后洗手或手消毒。

### 补充三：监测

- 每季度监测物体表面、医务人员手、空气的消毒效果；暴发、新建/改建、消毒方法改变时随时监测。
- 目标性监测 VAP、CLABSI、CAUTI、MDRO；分析发病率、部位构成、病原谱。
- 暴发识别：报告、流行病学调查、必要时同源性鉴定。

### 补充四：鉴别

- 器械相关感染 vs 其他来源：先看器械暴露时间与局部/血培养证据，再排除其他感染灶。
- 定植 vs 感染：培养阳性但无炎症表现，按定植处理。
- 非感染性发热：术后吸收热、药物热、输血反应、肺栓塞等需鉴别。

## 补充：术语与定义

509 的术语与三管专项标准有一处重要差异，先列定义：

| 术语 | 要点 |
|---|---|
| 重症监护病房（ICU） | 集中监护和救治重症患者的专业病房，为器官/系统功能障碍或高危患者提供监护与救治 |
| 空气洁净技术 | 通过多级空气过滤清除悬浮微粒与微生物，创造洁净环境 |
| 中央导管 | 末端位于或接近心脏或大血管的血管导管，用于输液、输血、采血、血流动力学监测 |
| 目标性监测 | 针对高危人群、高发部位、高危因素的监测，如 ICU、血液净化、手术部位、抗菌药物与耐药监测 |
| 器械相关感染 | 使用器械期间或停用后 48 小时内出现的相关感染；超过 48 小时需有证据表明与该器械相关 |
| CLABSI | 留置中央导管期间或拔除后 48 小时内发生的原发性、与其他部位感染无关的血流感染 |
| VAP | 建立人工气道并接受机械通气时发生的肺炎，包括肺炎发生前 48 小时内使用过人工气道者 |
| CAUTI | 留置导尿管期间或拔除后 48 小时内发生的尿路感染 |
| 医院感染暴发 | 短时间内发生 3 例以上同种同源感染病例 |

> **三管术语口径**：CLABSI、CRBSI、VCAI 都同时具备发病率监测与临床诊断意义，没有标准或文献否定任一定义的监测或临床价值；三者都可用于任何科室的发病率监测、临床诊断与质量指标监控，不与 ICU 或某一科室绑定；按使用目的和定义严格程度选择，不是互斥关系。本条的 CLABSI（Central Line-Associated Bloodstream Infection，中央导管相关血流感染）是监测定义，也用于临床诊断；相关标准和文献未强制要求导管尖端培养，但不等于“不要求”，导管尖端培养、差异阳性时间、导管血定量等证据越多，诊断支持越强。CRBSI（Catheter-Related Bloodstream Infection，导管相关血流感染）是临床归因诊断，也可用于监测/质量评价；VCAI（Vascular Catheter-Associated Infection，血管导管相关感染）是《国卫办医函〔2021〕136号 血管导管相关感染预防与控制指南（2021年版）》的统称，含局部感染与血流感染，也用于监测与临床诊断。三者不能混用，详见《三管感染诊断速查》。

> **口径提醒**：《WS/T 509—2016 重症监护病房医院感染预防与控制规范》的 VAP 定义没有写“机械通气满 48 小时”，比《WS/T 863-2025 呼吸机相关肺炎预防与控制标准》《呼吸机相关性肺炎预防、诊断和治疗指南（2013）》《中国成人医院获得性肺炎与呼吸机相关性肺炎诊断和治疗指南（2018年版）》宽。判定 VAP 时应以这三份文件的 48 小时定义为准；本条用于 ICU 监测术语时，不要放宽时间窗。
