## 1. 判定边界

VAP 需同时满足：

| 条件 | 解读 |
|---|---|
| 人工气道 | 气管插管或气管切开 |
| 机械通气 | 接受机械通气满 48 小时后发生的肺炎 |
| 时间归属 | 发生肺炎前 48 小时内曾使用人工气道通气者，也纳入 VAP |

注意：

- 48 小时按通气时长计算，不是"住院第 3 天"。
- 无创通气不属于本标准定义的 VAP（无人工气道）；但无创通气患者发生肺炎仍属医院获得性肺炎，需另行判定。
- 本标准是**预防与控制**标准，不是临床诊断标准；临床诊断需结合症状、影像与病原学（见 2018/2013 指南解读）。

## 2. 管理要求

- 使用呼吸机的科室将 VAP 防控纳入医疗质量与安全管理。
- 明确各类人员职责，制定并落实制度与标准操作规程。
- 感控、医务、护理等部门按专业范围监督，制定依从性核查表并督促落实。
- 制定培训计划，内容随证据与本地流行病学更新，并考核反馈。
- 使用呼吸机的医务人员应接受呼吸机操作与感染防控训练。
- 执行手卫生与隔离规范（标准预防 + 传播途径隔离）。

## 3. 预防措施

| 措施 | 要点 |
|---|---|
| 插管指征 | 严格掌握；需要辅助通气者首选无创通气 |
| 插管路径 | 宜经口，不宜经鼻 |
| 每日评估 | 每天评估呼吸机与气管插管的必要性，尽早脱机/拔管 |
| 体位 | 无禁忌者床头抬高 30°–45° |
| 口腔护理 | 每 6–8 小时一次 |
| 肠内营养 | 评估误吸风险；高风险者宜鼻肠管；条件允许尽早拔除 |
| 耐药菌管理 | MDRO 感染/定植者按隔离规范处置 |
| 抗菌药物预防 | 不以抗菌药物（全身或呼吸道局部）预防 VAP |
| 选择性脱污染 | 不宜常规口服抗菌药物做选择性消化道脱污染 |
| 镇静 | 使用镇静剂者每日评估停用或减量 |
| 集束化 | 宜将多项措施组合为 Bundle 同步实施 |

## 4. 气道管理

| 项目 | 要点 |
|---|---|
| 导管选择 | 型号合适；监测气囊压力，维持 25–30 cmH₂O |
| 声门下吸引 | 预计留置超过 72 小时者，宜选带声门下分泌物吸引功能的导管 |
| 吸痰 | 转运、翻身、调整插管位置、气道分泌物积聚时及时吸引；遵循无菌操作 |
| 管路更换 | 连续通气者不常规频繁更换呼吸机管路；污染或故障时更换 |
| 冷凝水 | 集水杯处于管路最低位；翻身/改变体位前先清除；清除时保持管路密闭 |
| 湿化 | 宜用加温湿化器或湿热交换器；不宜用微量泵持续泵入湿化液 |
| 湿化用水 | 加温湿化器使用无菌水 |
| 湿热交换器 | 宜 5–7 天更换；污染或气道阻力增加时及时更换 |
| 雾化 | 宜一次性雾化器及管路；复用者一人一用一消毒 |
| 密闭式吸痰 | MDRO、呼吸道传染病或疑似患者宜用密闭式吸痰管 |
| 呼出端过滤 | 呼吸道传染病或疑似患者可在呼出端加细菌过滤器 |

## 5. 消毒灭菌

| 对象 | 要求 |
|---|---|
| 复用外部管路/配件 | 由消毒供应中心集中清洗消毒；一人一用一消毒；长期使用者每周更换 |
| 呼吸机外壳/按钮/面板 | 保持清洁干燥，每日至少擦拭消毒 2 次；污染随时消毒；每位患者使用后终末消毒 |
| MDRO/暴发 | 增加清洁消毒频次 |
| 加温湿化器/活瓣/管路 | 一人一用一丢弃或消毒；污染或故障及时更换 |
| 内部管路 | 按产品说明书与呼吸机临床应用规范 |
| 环境表面 | 床栏、床头桌、呼叫按钮等定时清洁消毒；污染随时消毒；终末消毒 |
| 隔帘 | 保持清洁干燥；污染及时更换；MDRO 患者使用后终末消毒 |

## 6. 监测

- 按医院感染监测规范开展 VAP 目标性监测，定期分析、总结、反馈。
- 定期监测防控措施依从性，持续质量改进。
- 呼吸机清洗消毒效果监测按相关规范执行。

## 7. 常见误区

1. 把无创通气患者发生的肺炎直接算作 VAP。
2. 用"住院天数"代替"机械通气 48 小时"。
3. 只做口腔护理、不评估镇静与脱机，措施碎片化。
4. 气囊压力不监测，过高损伤黏膜、过低导致误吸。
5. 常规频繁更换呼吸机管路，增加污染机会。
6. 集水杯位置不当或冷凝水倒流。
7. 用微量泵持续泵入湿化液替代规范湿化。
8. 对 MDRO 患者未采取隔离或密闭式吸痰。
9. 以抗菌药物雾化/局部使用"预防"VAP。

## 8. 与工作台评分条目的对应

| 评分层 | 对应事实 |
|---|---|
| 器械暴露 gate | 人工气道类型、机械通气起止时间、是否满 48 小时 |
| 临床层 | 新浸润影、发热、脓性分泌物、白细胞异常 |
| 病原学层 | 下呼吸道标本培养、定量阈值、血培养 |
| 防控核查 | 床头角度、气囊压力、声门下吸引、口腔护理频次、每日脱机评估、管路管理 |
| 排除项 | 无创通气、肺水肿/ARDS/肺栓塞/肺不张等非感染性原因 |

## 补充：术语、鉴别与实施细节

### 补充一：术语

| 术语 | 含义 |
|---|---|
| 人工气道 | 为保持气道通畅建立的人工连接，包括气管插管、气管切开 |
| 机械通气 | 用装置替代或控制自主呼吸 |
| 无创正压通气 | 不经人工气道的正压通气，经鼻/面罩等连接 |
| 有创机械通气 | 经气管插管或气管切开的通气 |
| 声门下分泌物吸引 | 气囊上方开孔引流积聚分泌物，减少误吸 |
| 湿热交换器 | 回收呼出气热量与水分的装置，兼有过滤作用 |

### 补充二：鉴别

- 肺不张、肺水肿、ARDS、肺栓塞：可有浸润影与低氧，但无感染证据；需结合病史、影像、BNP、超声等。
- 其他肺炎：社区获得性肺炎、术后肺炎、免疫抑制相关肺炎；按发病时间与暴露判断。
- 气道定植：机械通气患者气道常有革兰阴性杆菌、念珠菌定植；培养阳性需结合定量、涂片与临床。
- 呼吸机相关性气管支气管炎：无新浸润影，仅有气道炎症表现，不按 VAP 计。

### 补充三：实施细节

- 气囊压力：用专用压力表测量并记录，维持在 25–30 cmH₂O；吸痰、翻身、转运后复测。
- 口腔护理：每 6–8 小时一次；使用有消毒作用的含漱液时注意避免误吸，操作前评估气囊压力。
- 声门下吸引：预计通气超过 72 小时者优先选择带吸引腔的导管；吸引时严格无菌。
- 闭式吸痰：MDRO、呼吸道传染病或疑似患者优先；按规范更换。
- 呼出端过滤器：呼吸道传染病或疑似患者使用；污染或阻力增加时更换。
- 湿化：加温湿化器用无菌水；湿热交换器 5–7 天更换，污染或阻力增加随时更换。
- 冷凝水：集水杯保持最低位，翻身前清空，清除时保持管路密闭。

### 补充四：监测指标

- VAP 发病率（每千机械通气日）、器械使用率。
- 防控措施依从性：床头角度、气囊压力、口腔护理、每日脱机评估。
- 呼吸机清洗消毒效果监测。
