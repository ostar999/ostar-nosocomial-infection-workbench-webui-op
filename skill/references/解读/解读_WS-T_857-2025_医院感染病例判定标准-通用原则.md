## 1. 定位：判定口径，不是临床诊断

这份标准解决的是"这例要不要算作医院感染"，属于感控报告口径；它不负责临床诊断与治疗决策。两者可能不一致：

| 维度 | 本标准关注 | 临床诊断关注 |
|---|---|---|
| 目的 | 感染是否与本次就医/住院相关，是否需上报 | 患者当前是否需要治疗、如何治疗 |
| 证据 | 时间关系、潜伏期、部位、病原体、排除条件 | 症状体征、影像、实验室、病原学、治疗反应 |
| 结论 | 是/否医院感染，属于哪一分类 | 具体疾病诊断与鉴别 |

因此报告中应把"判定层"与"诊断层"分开写，避免用临床诊断替代判定，也避免用判定口径否定临床治疗。

## 2. 核心概念

| 概念 | 解读 |
|---|---|
| 医院感染 | 住院患者或医院工作人员在医院内获得的感染；可在住院期间出现表现，也可在出院后出现 |
| 医源性感染 | 门急诊停留不足 48 小时者，在接受医学服务过程中因病原体传播而获得的感染 |
| 重复感染时间窗 | 从首次满足判定标准之日起 14 天内；同一部位、同类型（相同或不同病原体）的再次感染不另计为新病例 |
| 定植 | 体表或腔道有微生物生长，但没有相应感染表现；定植不等于感染，需排除 |

## 3. 判定依据（满足其一即可判定）

| 情形 | 解读要点 |
|---|---|
| 有明确潜伏期的感染 | 从入院到发病的时间超过该病原体的平均潜伏期；不足潜伏期者视为入院时已处于潜伏期 |
| 无明确潜伏期的感染 | 入院 48 小时后发生；48 小时是判定门槛，不是"住院第 3 天" |
| 与上次住院直接相关 | 本次感染与上一次住院存在直接因果关系（如上次手术/置管后的后续感染） |
| 原部位出现新部位感染 | 原有感染部位之外出现新的感染灶；需排除脓毒症的迁徙病灶与原感染的并发症 |
| 新生儿经产道/胎盘获得 | 出生后 48 小时内出现感染证据者不判定；48 小时后发生者按医院感染判定 |
| 工作人员职业暴露 | 在医院内因工作获得的感染，按医院感染判定 |

## 4. 排除依据（命中则不能简单判为医院感染）

| 排除情形 | 解读 |
|---|---|
| 入院时已存在感染的自然扩散 | 原有感染向邻近部位蔓延，一般不另计新感染；除非病原体或表现强烈提示新发感染 |
| 重复感染时间窗内同类型感染 | 首次判定后 14 天内，同部位同类型再次感染不另计 |
| 开放性伤口仅有定植 | 有细菌生长但无炎症表现，不算感染 |
| 创伤或非生物性刺激引起的炎症 | 如化学、物理因素导致的炎症反应，需与感染鉴别 |
| 新生儿出生 48 小时内感染 | 经产道/胎盘获得的病原体（如单纯疱疹、风疹、巨细胞病毒、梅毒、弓形虫等）在 48 小时内出现证据者不判定 |
| 特定长潜伏期病原体 | 芽生菌、球孢子菌、组织胞浆菌、副球孢子菌、隐球菌、肺孢子菌等，多为社区获得，一般不判为医院感染；除非有强烈证据提示院内获得 |
| 潜伏感染被激活 | 免疫抑制后带状疱疹、单纯疱疹、梅毒、结核等潜伏感染再激活，不按医院感染判定 |

## 5. 判定流程（建议按顺序核对）

1. **建立基线**：入院时已有什么感染、处于什么潜伏期、有哪些定植。
2. **画时间轴**：入院时间、症状出现时间、病原学采样时间、器械/手术时间。
3. **套潜伏期**：有明确潜伏期者先比较平均潜伏期；无明确潜伏期者看是否超过 48 小时。
4. **定部位**：是新部位感染，还是原感染扩散/并发症；是否属于迁徙病灶。
5. **查重复窗口**：14 天内同部位同类型感染是否已计过一次。
6. **排除非感染与定植**：炎症是否由创伤/理化因素引起；培养阳性是否为污染或定植；特殊病原体是否符合排除条件。
7. **归类命名**：按附录的分类名称落到具体部位与类型（如导尿管相关尿路感染、表浅切口感染等）。

### 5.1 常见分类（按系统，便于命名）

| 系统 | 常见类型（举例） |
|---|---|
| 泌尿系统 | 有症状尿路感染、无症状菌尿、肾/输尿管/膀胱/尿道等其他泌尿系统感染 |
| 手术部位 | 表浅切口、深部切口、器官/腔隙感染 |
| 血流 | 实验室证实的中心静脉导管相关血流感染、黏膜屏障损伤相关血流感染 |
| 上呼吸道 | 咽炎、喉炎、会厌炎 |
| 下呼吸道 | 肺炎（呼吸机相关、术后、其他）、不伴肺炎的支气管炎/气管支气管炎、肺脓肿、感染性胸膜炎 |
| 骨关节 | 骨髓炎、椎间隙感染、关节/关节腔感染、假体周围感染 |
| 中枢神经 | 颅内感染、脑膜炎/脑室炎、脊髓脓肿 |
| 心血管 | 血管感染、心内膜炎、心肌炎/心包炎、纵隔炎 |
| 眼耳鼻喉口腔 | 结膜炎及其他眼部感染、耳炎/乳突炎、口腔感染、鼻窦炎 |
| 消化系统 | 胃肠炎、胃肠道感染、病毒性肝炎（院内获得）、腹腔感染、坏死性小肠结肠炎、抗菌药物相关性腹泻 |
| 生殖系统 | 子宫内膜炎、会阴切口感染、阴道残端感染、其他生殖道感染 |
| 皮肤软组织 | 皮肤/软组织感染、压力性损伤感染、烧伤感染、乳腺脓肿/乳腺炎、脐炎等 |
| 全身性 | 播散性感染（如麻疹、风疹、腮腺炎等出疹性传染病） |

## 6. 常见判定误区

1. **把"入院 48 小时后"机械理解为住院第 3 天**：应按小时计算，且以发病/采样时间为准。
2. **忽略潜伏期**：有明确潜伏期的病原体，即使超过 48 小时，未超过平均潜伏期也不能判定。
3. **不做基线**：入院时已有感染或定植未记录，后续无法区分"新发"与"原有"。
4. **重复感染时间窗用错**：14 天内同部位同类型不另计；不同部位或不同病原体需按规则判断。
5. **把定植当感染**：痰、尿、伤口分泌物培养阳性但无炎症表现，不能直接判定。
6. **把非感染性炎症当感染**：术后吸收热、理化刺激、肺水肿、ARDS 等需鉴别。
7. **特殊病原体未核对**：隐球菌、肺孢子菌等长潜伏期病原体，默认按社区获得处理，除非有院内传播证据。
8. **把潜伏感染再激活判为院内感染**：带状疱疹、结核再激活等不属医院感染。
9. **新生儿时间窗混淆**：48 小时内与 48 小时后的判定结论相反。
10. **判定层与诊断层混写**：报告应分别给出"是否医院感染"与"临床诊断是什么"。

## 补充：判定场景、鉴别与条款实施

### 补充一：常见判定场景

| 场景 | 判定思路 |
|---|---|
| 术后 30 天内切口感染 | 先按 SSI 的时间窗与解剖层次分类，再确认是否满足医院感染的总体时间关系 |
| 拔管后 48 小时内肺炎 | 若此前有创通气满 48 小时，按 VAP 思路；否则按 HAP 或其他类型判断 |
| 14 天内同部位再发 | 落在重复感染时间窗内，同类型不另计新病例；跨出窗口才考虑新发 |
| 出院后出现感染表现 | 仍可能判为医院感染，关键是能否与本次住院建立直接关系 |
| 新生儿出生 48 小时内感染 | 经产道/胎盘获得的不判；48 小时后出现者按医院感染 |
| 免疫抑制后带状疱疹、结核复燃 | 属潜伏感染激活，不判医院感染 |
| 入院时已有感染、住院期间加重 | 属原有感染自然进展，一般不另计；除非出现新部位或病原体强烈提示新感染 |
| 长期留置导管相关感染 | 先按导管相关感染专项标准判断，再回到通用原则核对时间窗与排除项 |

### 补充二：鉴别的四个问题

1. **是不是感染**：有无炎症表现、影像/实验室证据；培养阳性是否只是定植或污染。
2. **是不是入院时就有**：入院时症状、影像、培养与潜伏期；入院 48 小时内出现者尤其要查基线。
3. **是不是新部位**：与原感染部位的关系；是否属于迁徙病灶或原感染并发症。
4. **是否落在重复窗口**：首次判定日期后的 14 天内，同部位同类型不另计。

### 补充三：条款实施细节

| 条款 | 实施要点 |

| 4.4 | 入院时已存在或已处于潜伏期的感染要排除；这要求入院记录里有基线信息 |
| 4.5 | 医院感染可以在住院期间表现，也可以在出院后表现；出院后发病不能自动排除 |
